# Review protocol

Each numbered stage is frozen before five independent reviewers are dispatched. Reviewers write separate reports and do not edit the manuscript or consult one another's reports. Every reviewer checks scientific validity and presentation; assigned emphases supplement that common responsibility.

Each report identifies:

- Verdict: no major issues, or revision required.
- Each issue's location, mathematical or textual claim, evidence, and proposed correction.
- Severity: major for a false or unsupported substantive claim, missing material hypothesis, consequential proof gap, incorrect source attribution, or structural omission affecting the result; minor for a local correctable clarification or presentation defect that does not invalidate the stated conclusion.
- Checks actually performed, including any source or numerical verification.

The coordinator records an adjudication of all findings. A different agent from the stage author fixes every valid issue. A new set of five independent reports is required after any accepted major issue. Reports from earlier rounds remain available for audit, but reviewers are asked to derive conclusions independently rather than vote on earlier verdicts.

A stage is closed only when no accepted major issue remains and every accepted minor issue has been corrected. Full-manuscript review additionally assesses logical dependencies, notation, scope, relevance, attribution, reproducibility, and readability across sections.
