Build requirements: a standard TeX Live installation with latexmk, pdfLaTeX,
BibTeX, and the packages loaded by macros.tex.

From the source directory, run:

    latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex

The resulting manuscript is main.pdf. The source archive contains all local
inputs and assets required by main.tex. It does not require the original
research repository, network access, solver software, or experiment reruns.

To remove generated build files:

    latexmk -c main.tex
