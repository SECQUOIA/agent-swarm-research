# Bibliography assembly record

This is a complete draft for the 47 keys in `current-citation-requests.txt`, assembled from the preliminary checked subset, local literature packages, local companion manuscripts, existing project bibliographies, and a small number of publisher metadata pages. It is an identity and metadata assembly, not approval of the paper's citation scopes or theorem locators. The main literature lead and the separate classical-contract reviewers retain the final source audit.

The bibliography deliberately uses ASCII plus LaTeX accent commands so it works with the paper's T1, UTF-8, lmodern setup. The Lee--Pham author field uses the safe ASCII romanization `Pham, Tien-Son`; the local metadata record carries the Vietnamese diacritics. No author name is assigned to our paper or to any companion manuscript.

Status meanings below: **readable/read** means a primary text is available in the cited local package and marked read; **retrieved/unread** means a primary file is present but the package marks it unread; **metadata-only** means only bibliographic metadata is available locally; **unretrieved** means no primary source text is in the literature package. A source can be readable without its publisher-formatted version being available. I do not use page or theorem locators from a version marked unread.
