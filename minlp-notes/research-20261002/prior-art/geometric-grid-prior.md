# Prior-art check: geometric-grid dynamic programming under quadratic growth

Date: 2026-10-02. This is a focused, read-only prior-art scan for the candidate
result in [theorem.md](../geometric-dp/theorem.md). It is not a literature-KB
maintenance run or a priority clearance.

## Finding

The strongest matches establish several ingredients and nearby algorithms,
including interval dynamic programming with global lower-bound messages for
tree-network OPF. The focused search did not identify the full proposed combination: a single
globally shared, recentered geometric grid for a mixed product box; a valid
global lower bound from unary second-order mesh corrections; contraction of the
global corrected-grid minimizer under global quadratic growth; and the resulting
treewidth-dependent polylogarithmic accuracy cost, including exact termination
on integer boxes. This is a search result, not proof of novelty.

The novelty claim should stay at that combination. Finite-state min-sum dynamic
programming on a tree decomposition is classical. Geometric meshes, second-order
interpolation error bounds, adaptive discretization of continuous graphical
models, and exact tree dynamic programs for sparse quadratic objectives each
have prior art. The contribution to test is whether the global certificate and
QG contraction make these pieces work together with the stated complexity for
the broader mixed-box, bounded-treewidth class.

## Classical components and likely contribution boundary

The finite-grid DP is standard: once every variable has a finite shared domain of size at most `q`, exact min-sum on a supplied decomposition uses `O((N+M)q^(w+1))` table work, up to width-dependent index costs, where `M` is the factor count. Processing children successively handles arbitrary branching; it does not require a product over child-message tables.

The one-dimensional `L Delta^2/8` interpolation scale is also classical. For a function with a one-sided second-derivative bound, endpoint interpolation error is quadratic in cell width. The candidate’s useful step is the specific penalty at grid nodes, summed as unary terms, together with the randomized endpoint-rounding argument that makes the corrected-grid minimum a global lower bound. The reviewed neighboring algorithms approximate messages or prune parametric quadratic pieces; none of the sources above supplied this same global lower-bound certificate.

Geometric spacing by `h + theta r` is a standard way to use `O(theta^(-1) log(s/h))` nodes across a box. The claimed algorithmic step is to recenter this shared grid on each corrected-grid minimizer and show a global squared-distance contraction from quadratic growth. That is the mechanism that changes a uniform mesh’s `1/eps`-type state count to a polylogarithmic accuracy dependence. No exact prior source found in this focused scan had that full contraction-plus-certificate construction.

This overlaps conceptually with the older trajectory-corridor idea. Heidari et al.'s DDDP forms each stage's state set from only `T^m` selected offsets around a trial trajectory and calls their union a corridor; each Bellman pass is constrained to that corridor, and the next pass is centered on its locally improved trajectory (pp. 274–75). They permit reducing offset sizes between passes (p. 275), but warn that poor choices can converge to a local minimum or maximum (p. 281); in their example, when the offset values are unknown, the result is only an approximation to optimum (p. 280). The candidate also uses the previous DP solution as a recentering point. Its analyzed invariant differs: every stage retains the whole product box in a shared grid, subtracts an explicit unary correction that certifies a lower bound over the original domain, and uses global quadratic growth to bound aggregate squared distance of the corrected-grid minimizer. A DDDP-style corridor can exclude remote global optima unless separately justified; the candidate's coarse remote cells remain represented and are paid for by larger corrections. The full-text comparison confirms the conceptual overlap in recentering while sharpening the distinction: DDDP's neighborhood restriction is a memory-saving heuristic iteration with no stated global lower certificate or QG-conditioned log-accuracy rate.

The project's continuous follow-up, [“Rebuilding graded decomposition certificates gives aggregate contraction”](../regridded-certificates/note.md), shares the old idea of rebuilding local search regions around a prior consistent solution, but it operates in a certificate model. It rebuilds graded bag and separator partitions, uses subtree gradients evaluated at the current center, and tracks aggregate copy error rather than requiring every bag copy to lie within a fixed sup-norm radius. Under global quadratic growth, Lipschitz gradients, a quadratic relaxation-error bound, bounded variable occurrence, and an exact attaining convex-minimization oracle, the reviewed draft handles branching trees and boundary minima. It reports final certificate size `O(N (4/theta)^p (J+1))`, created-box count `O(N (4/theta)^p (J+1)^2)`, and exact convex-oracle calls `O(N 3^p (4/theta)^p (J+1)^3)`, where `J=O(log(N/eps))` and `theta` is chosen from conditioning parameters. That model-specific lower-bound certificate and complexity proof is the possible novelty; trajectory-centered corridor refinement itself is old. This follow-up has a stronger oracle contract than DDDP and the shared-grid theorem: exact gradients and exact convex minima with attaining points.

## Rational encoding height for exact QP recovery

Polynomial encoding length of a rational QP optimizer is an established ingredient. Vavasis, [“Quadratic programming is in NP”](https://doi.org/10.1016/0020-0190(90)90100-C), proves the decision problem has polynomial-size rational witnesses. A precise statement useful here is restated by Del Pia, Dey, and Molinaro, [“Mixed-integer quadratic programming is in NP”](https://arxiv.org/abs/1407.4798), Theorem 3 (p. 3): for a rational continuous QP whose optimum is attained, a rational linear equation system of input-polynomial complexity has a global optimizer as its solution. The theorem supplies a polynomial-bit rational global optimizer, even without uniqueness or convexity; evaluating a rational quadratic objective there gives a polynomial-bit rational optimum value.

For the narrower case of a rational box QP with a unique optimum, the same height bound also follows directly. Fix the coordinates at active box bounds. The remaining coordinates lie in the relative interior of that face, so their gradient vanishes there; uniqueness forces the reduced Hessian on the free coordinates to be positive definite. Solving this nonsingular rational linear system and applying Cramer's rule bounds the optimizer's encoding length polynomially in the input size. This is a standard height observation, not a novelty claim. Any new exact corollary should be credited for turning the approximation and global certificate into exact rational recovery with the stated treewidth/conditioning runtime; Vavasis's result supplies existence of a short rational optimizer, not that dynamic program or runtime.

Munos and Moore's full paper, [“Variable Resolution Discretization in Optimal Control”](https://people.eecs.berkeley.edu/~pabbeel/cs287-fa19/optreadings/MunosMoore-MLJ2001.pdf), is a stronger adaptive-discretization comparison than a bare heuristic. It develops local and nonlocal split scores for continuous-state MDP value and policy approximations and demonstrates improved empirical grids. The nonlocal criteria use influence and variance; the authors say variance only estimates approximation error and can fail on a coarse grid when its policy differs from the continuous optimum. It does not give the candidate's global additive lower-bound certificate or a QG-conditioned treewidth complexity theorem. Its scope is continuous-time/space optimal control and near-optimal policies, rather than finite-state minimization of a sparse factor objective on a supplied decomposition.

The resulting claim can be stated narrowly: under a unique global minimizer with global QG constant `c`, an upper coordinate-curvature bound `L`, and a supplied width-`w` factor decomposition, the corrected-grid DP certifies an additive `eps` solution with exact-oracle work bounded by a conditioning factor on the order of `max{1, sqrt(L/c)}^(w+1)` times a power `log^(w+2)(1/eps)`. For a purely integer box, the squared-distance guarantee eventually falls below one and identifies the exact integer minimizer. The unknown-`c` exact integer variant is now explicit in [extensions.md](../geometric-dp/extensions.md). With `p=w+1`, `N` bags, `M` factors, `theta_* = 2^(-m_*-1)`, and `J_* = max{0, ceil(log2(s sqrt(n)/theta_*))}`, its explicit total table-work bound is `C^p (N+M) theta_*^(-p) (J_*+2)^(p+1)/(1-2^(-p))`. Here `m_*` is the first trial with `theta_*^2<=c/(8L)`; the denominator is the geometric sum over all earlier trials. The bit-complexity extension gives rational-polynomial bounds under its stated encoding and degree restrictions, not for arbitrary real oracles or arbitrarily large binary-encoded exponents.

Avoid broader claims such as “first treewidth dynamic program for continuous nonlinear optimization,” “first adaptive/geometric discretization in continuous DCOP,” or “first exact sparse quadratic DP.” Do not imply a Turing-time bound from the exact-oracle operation count. The global quadratic-growth constant can be small, and the theorem explicitly permits that conditioning cost to dominate.

## Open questions from this scan

- Could the width-two strong-NP-hard construction for box QP be adapted to retain a polynomially bounded global QG constant? If yes, it would sharply constrain bit-complexity interpretations of the candidate theorem. No such adaptation was established here.
- Does any older continuous graphical-model or deterministic global-optimization source use a shared nodewise curvature correction as a global lower bound, even if it does not use the same contraction argument? That specific exact certificate was not located.
- The integer convex literature handles large domains under separability or structured linear constraints. A targeted search of treewidth/treedepth IQP sources did not find an algorithm matching the candidate’s general sparse nonlinear factorization plus global QG assumptions.
- Near-optimality-dimension and bandit partitioning results are being checked in a parallel scope; this report does not adjudicate that comparison.
