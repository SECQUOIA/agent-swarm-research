# Scientific framing revision

User authorization: implement the five recommended clarity changes using the
previous staged author/five-independent-reviewer/separate-correction process.
Preserve scientific results, conservative interpretation, primary attribution,
full denominators and original experimental records. Do not upgrade the novelty
claim merely by rewriting it. No new experiments are needed for presentation
unless scrutiny identifies a substantive unresolved question.

| Stage | Authored deliverable | Review gate |
|---|---|---|
| R1 | Research problem and contribution stated early; abstract and introduction distinguish method, findings, validation and artifacts; conclusion synthesizes scientific lessons | One author, then five independent reviewers; separate agent resolves every valid finding, with a repeat five-review round after major corrections |
| R2 | Experiments organized around capability, failure mechanisms, and costs; chronological repair detail retained at appropriate depth; current documentation/source/PDF integrated and packaged | Same author/review/correction gate, preserving all numerical records and supported claims |
| R3 | Final whole-manuscript assessment of the completed integrated revision and standalone delivery | Five independent full reviews; coordinator adjudication and separate corrections; repeat after any major issue |

Complete each stage before starting the next. The coordinator owns this ledger
and adjudications; authors/reviewers/correction agent have separate assignments.
Reviewers do not read one another's reports before handing off. Dated earlier
review records remain historical evidence. Scientific source/tests, formal
proofs and bulk evidence need no rebuild unless a substantive change requires it.
