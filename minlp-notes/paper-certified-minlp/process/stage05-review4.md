In the delivered PDF it floats to page 23, before Section 6.3 defines `d` on page 24. Add a concise caption note identifying `d` as the signed normalized difference from an unverified reference, with a forward section reference or the formula, and stating that reference counts concern verified records. Optionally label the uniform column as the frozen V1 replay to preserve its source-version scope when read on its own. Update the generating script along with generated text and any packaged table copies. This is a table-explanation issue, not an error in the counts or metric.
