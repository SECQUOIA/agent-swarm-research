# Topic 27 frozen claims

Status: all frozen obligations proved; see [coverage](COVERAGE.md) and
verification. These obligations come
from the independent source inventory, not from whichever
proofs happen to be easiest to implement. Identifiers name mathematical
obligations, not predetermined Lean declaration names.

For positive finite dimensions `n,m`, let `A_i` be real symmetric matrices,
`b_i` real vectors, and `c_i` real scalars. Write
`f_i(x)=x^T A_i x+2 b_i^T x+c_i` and `S={x : ∀i, f_i(x)<0}`. Aggregation
weights are real. A nontrivial convex certificate has `lambda_i>=0`,
`lambda!=0`, `A_lambda` PSD, and `(A_lambda,b_lambda)!=(0,0)`.

| ID | Required conclusion |
|---|---|
| Q01 | Define the actual strict system, homogeneous quadratic map, finite nonnegative coefficient aggregates, PSD predicate, and nontrivial certificate. Establish that the abstract quadratic or bilinear representation used in proofs agrees with the symmetric-matrix system above. |
| Q02 | Define HHC as convexity of the homogeneous image of every linear hyperplane, and asymptotic hyperplane convexity as convexity on an unbounded increasing sequence of levels `H_(alpha,s)={ (x,t) : alpha·x=s t }` for every nonzero `alpha`. Prove HHC implies the latter. An equivalent unbounded-level formulation requires a proved equivalence or a direct implication from the source hypothesis. |
| Q03 | For every strict feasible point and every nonzero nonnegative weight vector, the aggregated value is strictly negative. A trivial certificate therefore has `c_lambda<0` when `S` is nonempty. |
| Q04 | Prove the easy implication without HHC or asymptotic convexity: a nontrivial convex certificate places `conv(S)` in a proper convex strict sublevel set. Prove properness for both nonzero PSD quadratic part and zero quadratic but nonzero linear part. |
| Q05 | Source Lemma 1: a common direction with all quadratic parts strictly negative makes every point a midpoint of two feasible points, hence `conv(S)=univ`. Deduce that a proper hull has no strict homogeneous feasible point with `t=0`. |
| Q06 | Obtain a nonzero supporting functional `alpha` and real `beta` with `alpha·x<beta` on `S` when the nonempty strict system has proper hull. Prove source Lemma 2: all `H_(alpha,s)` with `s>=beta` miss the strict homogeneous feasible set, including the `t=0` and `t!=0` cases. |
| Q07 | Source Lemma 3: two closed cones `P,D` in a finite-dimensional real normed space, with `P∩D={0}`, have a constant `kappa>0` such that `dist(p,D)>=kappa*norm(p)` for all `p∈P`; the source additionally assumes finite generation of `P`. Prove the zero-cone case and the scaling step. Establish closedness of the finitely generated coefficient cone used below, rather than adding it as a headline premise. |
| Q08 | Separate each convex homogeneous hyperplane image missing the open negative orthant to obtain actual nonzero nonnegative weights, normalized by `sum_i lambda_i=1`, whose aggregate is nonnegative everywhere on that hyperplane. Derive the explicit restriction formula for positive levels. |
| Q09 | Use strict feasibility to control the constant coefficient in the limiting argument. Either follow the source's simplex subsequence, obtaining a trivial PSD limit and eventual negativity of its constants, or bound every `c_lambda` above by `-q_(A_lambda)(x0)-2 b_lambda·x0` at a fixed strict feasible point and prove that this bound, after normalizing the quadratic and linear coefficients, makes the constant contribution vanish as levels tend to infinity. The limiting argument must not assume boundedness of `c_lambda/norm(A_lambda,b_lambda)`. |
| Q10 | Rule out the hyperplane certificates if every convex certificate is trivial. Use the actual closed cone generated by `(A_i,b_i)` and its intersection with the PSD cylinder, and handle zero aggregate pairs before normalizing. The source spectral estimate or an equivalent proved compactness contradiction is acceptable; the required conclusion must not be a new premise. |
| Q11 | Combine the preceding results into the full source Theorem 1: for every nonempty strict quadratic system with asymptotic hyperplane convexity, `conv(S)!=univ` if and only if a nontrivial convex certificate exists. The headline must apply to the original coefficients and actual convex hull, with no supplied separation, closedness, normalized-certificate, or limiting-certificate oracle. |
| Q12 | Specialize Q11 using Q02 to HHC, with the same nonemptiness and nontriviality assumptions and no unnecessary `n>=3` or `m>=2` restriction. This is the statement identified by the source as Blekherman–Dey–Sun Conjecture 3.3. |

Q01–Q03 set the semantics; Q04 proves one implication. Q05–Q10 establish
the other implication through supporting hyperplanes and compactness, with
Q07 also retained as an independently stated source lemma. Q11 and Q12 are
the required final interfaces. Stronger internal lemmas are acceptable, but
must retain an explicit bridge to these source statements.

The package excludes the source's Corollaries 1–5, Lemma 4, literature
novelty claims, example classifications, algorithms for testing HHC, numerical
SDP certification, and complexity bounds. These exclusions do not permit
weakening Q01–Q12 or presenting the unverified ancillary claims as formalized.
