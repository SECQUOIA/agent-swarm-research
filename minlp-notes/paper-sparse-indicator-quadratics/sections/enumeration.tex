\section{Counting and finding near-optimal supports}
\label{sec:enumeration}
This section proves the first three ingredients outlined in
Section~\ref{sec:main-result}: the count of near-optimal supports
(Lemma~\ref{lem:count}), their enumeration with an approximate oracle
(Lemma~\ref{lem:enumeration}), and the passage from single parameter
values to a whole parameter domain (Theorem~\ref{thm:dictionary}).
Section~\ref{sec:net-work} bounds the size of the net for a box and the
work per output. These results involve no quadratic functions and no
graph, so we state them for an arbitrary family of supports.

Let $Z\subseteq\{0,1\}^m$ be nonempty. We call its elements
\emph{supports}, identifying $z$ with the set $\{i:z_i=1\}$. Each support
has a deterministic cost plus a random linear perturbation $\xi^Tz$. For
a message $M_{I,S}$, the set $Z$ is $\{0,1\}^I$, the deterministic cost
of a support $A$ at a boundary value $t$ is its unperturbed branch
$q_A(t)$ from \eqref{eq:branch}, and adding the perturbation gives the
perturbed branch \eqref{eq:noisybranch}. If $m=0$, then $Z$ contains
only the empty support, and all statements hold with empty products
equal to one.

\subsection{Expected number of near-optimal supports}
Fix the parameter for now, so that each support has a single cost.
Assume that the coordinates $\xi_i$ of the perturbation are independent
real random variables satisfying
\begin{equation}\label{eq:intervalmass}
 \Prob\{\xi_i\in J\}\le\phi |J|+\tau
 \quad\text{for every closed interval }J,
 \qquad \phi>0,\quad\tau\ge0.
\end{equation}
The constant $\phi$ acts as a density bound: a density bounded by $\phi$
gives \eqref{eq:intervalmass} with $\tau=0$. The term $\tau$ allows
atoms. Atoms must be allowed because the perturbation grid used later is
finite, so exact ties occur with positive probability. For deterministic
costs $g_z\in\R$, which may be arbitrary but must not depend on $\xi$,
put
\[
 F_z=g_z+\xi^Tz,\qquad v=\min_{z\in Z}F_z,\qquad
 \mathcal N_a=\{z\in Z:F_z\le v+a\},\quad a\ge0.
\]
Thus $\mathcal N_a$ is the set of supports within $a$ of the optimum,
and $\mathcal N_0$ is the set of optimal supports.

Without the perturbation, $\mathcal N_a$ can be all of $Z$; for
instance, every support is optimal when all costs $g_z$ are equal. The
perturbation breaks such ties, and in this extreme case one can see
exactly how. Let $Z=\{0,1\}^m$ and $g_z=0$ for all $z$. Then
\[
 F_z-v=\sum_{i=1}^m\bigl(\xi_iz_i-\min\{\xi_i,0\}\bigr).
\]
The $i$th term equals $|\xi_i|$ if $z_i=1$ and $\xi_i>0$, or if $z_i=0$
and $\xi_i<0$; otherwise it is zero. A support in $\mathcal N_a$ must
therefore take the cheaper value of $z_i$ on every coordinate with
$|\xi_i|>a$, so $|\mathcal N_a|\le2^s$, where $s$ is the number of
coordinates with $|\xi_i|\le a$. By independence and
\eqref{eq:intervalmass},
\[
 \E\,2^s=\prod_{i=1}^m\bigl(1+\Prob\{|\xi_i|\le a\}\bigr)
 \le(1+2\phi a+\tau)^m.
\]
Many near-optimal supports would need many coordinates with a small
perturbation, and that is unlikely when $a$ is small.
Lemma~\ref{lem:count} below proves the same bound for an arbitrary
family $Z$ and arbitrary costs $g_z$.

For general costs, the near-optimal supports have no such coordinatewise
description, but the same mechanism works one coordinate at a time. Fix
a coordinate $i$ and all coordinates of $\xi$ other than $\xi_i$. Among
the supports with $z_i=0$, the least perturbed cost is then a fixed
number; among those with $z_i=1$, it is a fixed number plus $\xi_i$. If
both groups contain a support in $\mathcal N_a$, both least costs lie in
$[v,v+a]$, so they differ by at most $a$. This confines $\xi_i$ to a
fixed interval of length $2a$, which has probability at most
$2\phi a+\tau$. Splitting by one bit and conditioning on the other
coordinates of the perturbation is the conditioning argument of Beier
and V\"ocking's generalized isolating lemma
\cite[conference version, Lemma~5]{BeierVocking} (compare
\cite[Lemma~6.1]{RoglinTeng}); we apply it to several coordinates at
once. To turn such events into a bound on the size of $\mathcal N_a$, we
need to know that a large family of supports must vary freely on many
sets of coordinates. Shattering makes this precise.

A family $\mathcal F\subseteq\{0,1\}^m$ \emph{shatters} a coordinate set
$D\subseteq[m]$ if the restrictions $z_D$, $z\in\mathcal F$, include all
$2^{|D|}$ binary patterns. Write $\Sh(\mathcal F)$ for the collection of
coordinate sets shattered by $\mathcal F$. Every nonempty family
shatters the empty set, and $\mathcal F$ shatters $\{i\}$ exactly when
it contains supports with $z_i=0$ and with $z_i=1$. For example, the
family $\{00,10,01\}$ in $\{0,1\}^2$ shatters $\varnothing$, $\{1\}$,
and $\{2\}$, but not $\{1,2\}$, because the pattern $11$ is missing. The
sandwich inequality, in the form stated by Kozma and Moran
\cite[Theorem~5]{KozmaMoran}, says that a family shatters at least as
many sets as it has members:
\begin{equation}\label{eq:sandwich}
 |\mathcal F|\le|\Sh(\mathcal F)|.
\end{equation}
In the example both sides equal three. The family $\{00,11\}$ shatters
the same three sets, so the inequality can be strict.

For completeness, we recall the induction on $m$. Split $\mathcal F$ by
its last coordinate into projected families
$\mathcal F^0,\mathcal F^1\subseteq\{0,1\}^{m-1}$, and set
$\mathcal F^\cup=\mathcal F^0\cup\mathcal F^1$ and
$\mathcal F^\cap=\mathcal F^0\cap\mathcal F^1$, so that
$|\mathcal F|=|\mathcal F^\cup|+|\mathcal F^\cap|$. Every set shattered
by $\mathcal F^\cup$ is shattered by $\mathcal F$. If $\mathcal F^\cap$
shatters $D$, then $\mathcal F$ shatters $D\cup\{m\}$. The two
collections are disjoint, because only the second contains $m$. With the
induction hypothesis for $\mathcal F^\cup$ and $\mathcal F^\cap$, this
gives $|\mathcal F|\le|\Sh(\mathcal F^\cup)|+|\Sh(\mathcal F^\cap)|
\le|\Sh(\mathcal F)|$. In the base case $m=0$, the family $\mathcal F$
is either empty, and shatters no set, or a single point, and shatters
only the empty set; in both cases $|\mathcal F|=|\Sh(\mathcal F)|$.

By \eqref{eq:sandwich}, a large set $\mathcal N_a$ must shatter many
coordinate sets, so it suffices to bound the probability that
$\mathcal N_a$ shatters a fixed set $D$.

\begin{lemma}[Near-optimal count]\label{lem:count}
Under \eqref{eq:intervalmass}, for every $a\ge0$,
\begin{equation}\label{eq:count}
 \E|\mathcal N_a|\le(1+2\phi a+\tau)^m.
\end{equation}
Here $|\mathcal N_a|$ counts every support in $\mathcal N_a$, including
tied ones.
\end{lemma}

\begin{proof}
Fix $D\subseteq[m]$ and condition on $(\xi_i)_{i\notin D}$. For a pattern
$u\in\{0,1\}^D$, define
\[
 C_u=\min_{z\in Z:\ z_D=u}
          \left(g_z+\sum_{i\notin D}\xi_i z_i\right).
\]
If some class $\{z\in Z:z_D=u\}$ is empty, then $Z$, and hence
$\mathcal N_a$, does not shatter $D$. Otherwise every $C_u$ is finite and
independent of $\xi_D$, and the smallest perturbed cost in class $u$ is
$C_u+\sum_{i\in D}\xi_iu_i$. If $\mathcal N_a$ shatters $D$, each class
contains a support in $\mathcal N_a$, so this smallest cost lies in
$[v,v+a]$ for every $u$. Let $\chi_i\in\{0,1\}^D$ have a single one, in
coordinate $i$. Comparing $u=0$ with $u=\chi_i$ gives
\[
 |C_{\chi_i}+\xi_i-C_0|\le a\qquad(i\in D).
\]
Given $(\xi_i)_{i\notin D}$, each condition places $\xi_i$ in a fixed
interval of length $2a$, and the coordinates $\xi_i$, $i\in D$, are
independent. By \eqref{eq:intervalmass}, the conditional probability
that $\mathcal N_a$ shatters $D$ is at most $(2\phi a+\tau)^{|D|}$, and
hence so is $\Prob\{D\in\Sh(\mathcal N_a)\}$. Taking expectations in
\eqref{eq:sandwich} with $\mathcal F=\mathcal N_a$ and summing over all
$D\subseteq[m]$ gives
$\E|\mathcal N_a|\le\sum_{D}(2\phi a+\tau)^{|D|}=(1+2\phi a+\tau)^m$.
\end{proof}

Section~\ref{sec:spectral} draws each $\xi_i$ uniformly from the
perturbation grid \eqref{eq:noisegrid}, whose $N$ points are equally
spaced in $[-\sigma,\sigma]$ with spacing $2\sigma/(N-1)$; the bounds
below hold for any $N\ge2$. An interval of length $d$ contains at most
$d(N-1)/(2\sigma)+1$ grid points, so its probability is at most
$d/(2\sigma)+1/N$. Hence
\begin{equation}\label{eq:gridmass}
 \phi=\frac1{2\sigma},\qquad\tau=\frac1N
\end{equation}
satisfy \eqref{eq:intervalmass}. Each grid point is an atom of
probability $1/N$, so the grid needs many points:
Theorem~\ref{thm:dictionary} below requires $\tau\le1/(2n)$, which is
why Theorem~\ref{thm:main} takes $N\ge2n$.

\subsection{Certified enumeration with a restricted additive oracle}
Still at a fixed parameter value, we now want to list every support in
$\mathcal N_\delta$, not only bound their expected number. The search
below divides the supports into groups by fixing some of their
coordinates, so the oracle must be able to optimize with coordinates of
$z$ fixed. It may be approximate, because the oracle of
Section~\ref{sec:spectral} solves a grid version of the problem.

A partial assignment $p$ fixes some coordinates of $z$. Its \emph{cell}
$Z_p$ is the set of supports in $Z$ that agree with $p$. A
\emph{restricted additive oracle} with accuracy $\varepsilon>0$ accepts
any partial assignment $p$. If $Z_p=\varnothing$, it reports this;
otherwise it returns a support $z_p\in Z_p$ together with its exact cost
$V_p=F_{z_p}$, where
\begin{equation}\label{eq:oracle}
 \min_{z\in Z_p}F_z\le V_p\le\min_{z\in Z_p}F_z+\varepsilon.
\end{equation}
The returned support may be suboptimal by up to $\varepsilon$, but its
reported cost is exact. Hence $\ell_p=V_p-\varepsilon$ is a certified
lower bound on all costs in $Z_p$.

The search keeps the supports not yet output partitioned into cells.
When it processes a cell, it outputs the support $z^{\rm out}$ returned
by the oracle and splits the rest of the cell according to the first
free coordinate at which a support differs from $z^{\rm out}$. For
example, let $m=3$, let $p$ fix nothing, and let $z^{\rm out}=101$.
Writing $*$ for a free coordinate, the other seven supports split into
the cells $0{*}{*}$, $11{*}$, and $100$: a support that differs from
$101$ in the first coordinate lies in the first cell, one that agrees
there but differs in the second lies in the second cell, and the only
remaining support is $100$. Each piece is again a cell, so the oracle
can be called on it.

Given a tolerance $\delta\ge0$, \emph{certified enumeration} proceeds as
follows; its stopping test uses only the certified lower bounds $\ell_p$.
\begin{enumerate}
\item Query the oracle on the empty assignment, whose cell is $Z$, and
 record its value $U$, which stays fixed.
\item Keep a heap of nonempty cells keyed by $\ell_p$, each stored with
 its returned support $z_p$. Start with the cell $Z$.
\item While the heap is nonempty and its smallest key is at most
 $U+\delta$, extract a cell $Z_p$ with the smallest key and output
 $z^{\rm out}=z_p$. Let $j_1<\cdots<j_r$ be the coordinates left free by
 $p$. For $s=1,\ldots,r$, form the child cell that keeps the fixed
 coordinates of $p$ and sets
 \begin{equation}\label{eq:children}
  z_{j_h}=z^{\rm out}_{j_h}\ (h<s),\qquad
  z_{j_s}=1-z^{\rm out}_{j_s}.
 \end{equation}
 Query the oracle on each child and insert the nonempty ones.
\item Return the set $E$ of output supports.
\end{enumerate}
The children in \eqref{eq:children} are the partition step of Lawler's
ranked enumeration \cite{Lawler}. Lawler uses an exact oracle and lists
solutions in order of cost. With an additive oracle the outputs are not
ranked; the certified stopping test gives the two-sided inclusion
\eqref{eq:inclusions} instead.

\begin{lemma}[Enumeration guarantee]\label{lem:enumeration}
Certified enumeration terminates, outputs no support twice, and returns a
set $E$ satisfying
\begin{equation}\label{eq:inclusions}
 \mathcal N_\delta\subseteq E\subseteq\mathcal N_{\delta+2\varepsilon}.
\end{equation}
It uses at most $1+m|E|$ oracle calls.
\end{lemma}

\begin{proof}
Each support in $Z_p$ other than $z^{\rm out}$ has a first free
coordinate $j_s$ at which it differs from $z^{\rm out}$, so it lies in
exactly one child \eqref{eq:children}. Hence the cells in the heap always
partition the supports not yet output; empty cells contain nothing and
are dropped. Outputs are therefore distinct, and the procedure terminates
because $Z$ is finite.

The value $U$ is the cost of a support, so $v\le U$. Suppose a support
$z$ with $F_z\le v+\delta$ has not been output. It lies in some heap cell
$Z_p$, and
$\ell_p\le\min_{y\in Z_p}F_y\le F_z\le v+\delta\le U+\delta$. Thus the
procedure cannot stop while $z$ remains, which proves
$\mathcal N_\delta\subseteq E$. Conversely, \eqref{eq:oracle} for the
first query gives $U\le v+\varepsilon$. An output comes from a cell with
$\ell_p\le U+\delta$, so
\[
 F_{z_p}=V_p=\ell_p+\varepsilon\le U+\delta+\varepsilon
                \le v+\delta+2\varepsilon.
\]
Finally, there is one call for the first query and at most $r\le m$
calls for the children of each output.
\end{proof}

The inclusions \eqref{eq:inclusions} hold for every realization of $\xi$
and for every oracle answer permitted by \eqref{eq:oracle}, including the
worst one. This is what allows Lemma~\ref{lem:count} to bound the output:
its probability bounds concern the sets $\mathcal N_a$, which are
defined without reference to the search, so they never condition on the
adaptive search history.

\subsection{A complete dictionary on a parameter domain}
Now let the costs depend on a parameter. Let $T$ be a nonempty compact
metric space, and let deterministic functions $q_z:T\to\R$ be
$L$-Lipschitz for a common $L\ge0$. Define the \emph{branches} and their
minimum
\[
 F_z(t)=q_z(t)+\xi^Tz,\qquad V(t)=\min_{z\in Z}F_z(t).
\]
A \emph{dictionary} for $V$ on $T$ is a set of branches whose pointwise
minimum equals $V$ on $T$. In Section~\ref{sec:spectral}, $T$ is a
separator box and $V$ is a message. For $t\in T$ and $a\ge0$, let
$\mathcal N_a(t)$ denote the set $\mathcal N_a$ defined with the costs
$g_z=q_z(t)$. A \emph{parameter net} with radius $r$ is a finite set
$t_1,\ldots,t_J\in T$ such that every point of $T$ lies within distance
$r$ of some $t_j$.

A support that is optimal somewhere on $T$ may be optimal only on a
region that contains no net point, or only at a single tie point, so the
theorem below enumerates near-optimal supports at each net point. The
net must be fixed before $\xi$ is drawn. At a point chosen after seeing
$\xi$, the costs depend on $\xi$ and Lemma~\ref{lem:count} does not
apply. For instance, a point where two branches tie for the minimum has
at least two optimal supports by construction.

Expectations of the sizes of random sets of supports require these sets
to depend measurably on $\xi$. The set of supports optimal somewhere on
$T$ does so automatically: a support $z$ is optimal somewhere exactly when
$\min_{t\in T}(F_z(t)-V(t))=0$, and this minimum is continuous in $\xi$
because $T$ is compact. For the enumeration outputs $E_j$ below, we assume
that the oracle's returned support is a measurable function of $\xi$ and
that all remaining ties, such as equal heap keys, are broken by fixed
deterministic orders.

\begin{theorem}[Complete dictionary from restricted approximation]
\label{thm:dictionary}
Suppose \eqref{eq:intervalmass} holds, $n\ge\max\{1,m\}$ is an integer,
and $\tau\le1/(2n)$. Set
\begin{equation}\label{eq:accuracy}
 \varepsilon=\delta=\frac1{12n\phi}.
\end{equation}
For $L>0$, take a deterministic parameter net $t_1,\ldots,t_J$ in $T$
with radius $\varepsilon/(2L)$. For $L=0$, take $J=1$ and any point
$t_1\in T$. At every $t_j$, run certified enumeration with tolerance
$\delta$ for the costs $F_z(t_j)$, using a restricted additive oracle
with accuracy $\varepsilon$. Let $E_j$ be its output and
$\mathcal D=\bigcup_j E_j$. Then, for every realization of $\xi$,
\begin{equation}\label{eq:dictionaryexact}
 \bigcup_{t\in T}\argmin_{z\in Z}F_z(t)\subseteq\mathcal D,
 \qquad V(t)=\min_{z\in\mathcal D}F_z(t)\quad(t\in T).
\end{equation}
Moreover,
\begin{equation}\label{eq:dictionarysize}
 \E\sum_{j=1}^J|E_j|\le eJ,
 \qquad\E[\text{number of oracle calls}]\le J(1+em).
\end{equation}
\end{theorem}

The branches $F_z$, $z\in\mathcal D$, thus form a dictionary for $V$ on
$T$. By the inclusion and the equality in \eqref{eq:dictionaryexact}, at
every $t\in T$, including tie points and points on the boundary of $T$,
the minimizers over $\mathcal D$ are exactly the minimizers over $Z$.
The integer $n$ only sets the tolerance; Section~\ref{sec:spectral}
takes it to be the problem dimension, so that one accuracy serves every
message.

\begin{proof}
Fix a realization of $\xi$, and let $z$ be a support that minimizes
$F_z(t)$ over $Z$ at some $t\in T$. The term $\xi^Tz$ does not depend on
$t$, so every branch is $L$-Lipschitz. First suppose $L>0$. Choose $t_j$
within distance $\varepsilon/(2L)$ of $t$, and let $y$ minimize at $t_j$.
Then
\[
 F_z(t_j)\le F_z(t)+\varepsilon/2
           \le F_y(t)+\varepsilon/2
           \le F_y(t_j)+\varepsilon.
\]
Thus $z\in\mathcal N_\varepsilon(t_j)=\mathcal N_\delta(t_j)$, and
Lemma~\ref{lem:enumeration} gives $z\in E_j$. If $L=0$, every branch is
constant, so $z$ is optimal at $t_1$ and lies in $E_1$. This proves the
inclusion in \eqref{eq:dictionaryexact}. Every element of $\mathcal D$
lies in $Z$, so $\min_{z\in\mathcal D}F_z(t)\ge V(t)$, and the inclusion
gives equality.

For the expectations, fix $j$. The point $t_j$ is deterministic, so the
costs $q_z(t_j)$ are deterministic and Lemma~\ref{lem:count} applies.
By Lemma~\ref{lem:enumeration}, the outputs at $t_j$ lie within
$\delta+2\varepsilon=3\varepsilon$ of the optimum, and
\eqref{eq:accuracy} makes $6\phi\varepsilon=1/(2n)$. With
$\tau\le1/(2n)$ and $m\le n$, Lemma~\ref{lem:count} gives
\[
 \E|E_j|\le\E|\mathcal N_{3\varepsilon}(t_j)|
 \le(1+6\phi\varepsilon+\tau)^m
 \le(1+1/n)^m\le e.
\]
Summing over $j$ gives the first bound in \eqref{eq:dictionarysize}.
Lemma~\ref{lem:enumeration} gives at most $1+m|E_j|$ oracle calls at
$t_j$, so the expected number of calls is at most $J(1+em)$. The same
$\xi$ is used at every net point; linearity of expectation needs no
independence between points.
\end{proof}

\subsection{Net size and work per output}\label{sec:net-work}
Let $T=[-R,R]^k$ with the Euclidean metric and $k,R,L>0$. Divide each
coordinate interval into $h=\max\{1,\lceil2kRL/\varepsilon\rceil\}$
equal intervals and use the midpoints of the resulting $h^k$ subboxes.
Every point of $T$ lies within distance $\sqrt{k}R/h\le kR/h\le
\varepsilon/(2L)$ of a midpoint, and
\begin{equation}\label{eq:netsize}
 J=h^k\le(1+2kRL/\varepsilon)^k.
\end{equation}
If $k=0$ or $R=0$, the box is a single point. Rational $R,L,\varepsilon$
give rational net points of polynomial encoding length. At fixed $k$, the
bound \eqref{eq:netsize} is a polynomial in $R$, $L$, and $1/\varepsilon$.

Theorem~\ref{thm:dictionary} bounds the expected numbers of outputs and
oracle calls. The remaining work is bookkeeping, and it costs at most a
polynomial factor per output or oracle call, even for a realization with
exponentially many outputs. At one net point, each of the at most $2^m$
outputs creates at most $m$ cells, so at most $1+m2^m$ cells are created
and each heap operation uses $O(m+\log(m+1))$ comparisons. Supports from
different net points can be deduplicated in a binary trie in $O(m)$ time
per output. Because these factors do not grow with the number of
outputs, only the first moment of the output count is needed. An
algorithm that outputs branches must also construct each branch from its
support. Hence, if exact evaluation of $F_z(t_j)$, construction of a
branch from its support, and each restricted oracle call have uniformly
polynomial bit cost, the expected bit cost is polynomial whenever $J$ is
polynomial.
