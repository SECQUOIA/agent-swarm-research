\begin{abstract}
We study positive-definite quadratic optimization with one binary indicator
for each continuous variable. Independent finite-grid perturbations of the
indicator penalties permit exact construction of every separator value
function on prescribed bounded boxes at fixed treewidth. The output contains
every support optimal anywhere, including at a single tie point. The algorithm
is correct for every draw and has polynomial expected bit complexity in the
input length, numerical coefficient and spectral bounds, box radius, and
inverse perturbation scale. It needs logarithmically many random bits per
coordinate and no deterministic support margin or graph-growth assumption.
The proof combines a near-optimal support count, certified enumeration from
restricted additive approximation oracles, and a parameter net; a finite-domain
dynamic program supplies the oracle. Complementary lower bounds explain
the restrictions. Exact optimization is NP-hard at bandwidth two with
near-identity matrices. Fixed local coefficients can generate exponentially
many indispensable scalar message formulas, although pruning admits matching
power-law bounds. On uniformly conditioned stars, an inverse-principal polytope
has a correlation-polytope face, and a specific exact decision-diagram state
scheme has exponential width even after row normalization. These representation
bounds are distinct from hardness of optimizing the original tree problem.
Supporting results give all fixed moments of active-label counts, polynomial
expected connected-region counts and exact labeled subdivisions at fixed
dimension, sharper scalar and planar estimates, and direct recursive
algorithms under diagonal dominance.
\end{abstract}
