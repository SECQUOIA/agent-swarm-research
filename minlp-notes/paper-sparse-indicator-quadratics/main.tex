\title{Sparse indicator quadratics:\newline exact complexity and smoothed separator messages}
\author{}

\begin{abstract}
We minimize a positive-definite quadratic in which each continuous
variable can be nonzero only if a penalized binary indicator is on. For
sparse matrices, exact dynamic programming over a tree decomposition
must pass functions, called messages, of the few continuous variables
shared by subproblems. Each message is the minimum of one quadratic per
choice of active indicators in the eliminated part, so few shared
variables bound its dimension but not its number of quadratics. We show
that perturbing each penalty by an independent uniform draw from a grid
in $[-\sigma,\sigma]$ makes exact messages efficient to compute in
expectation. For every draw, our algorithm solves the perturbed problem
and computes every message exactly on a box of radius $R$, as a list
containing every quadratic that attains the minimum somewhere on the
box. At fixed treewidth, its expected bit complexity is polynomial in
the input length and in $C$, $H$, $\mu^{-1}$, $R$, and $\sigma^{-1}$,
where $C$ bounds the linear coefficients and the eigenvalues lie in
$[\mu,H]$. The main tool lists, at finitely many points of the box,
every near-optimal choice of active indicators, using only an
approximate solver in which some indicators can be fixed. Two lower
bounds explain why the running time depends on numerical values and why
the penalties are perturbed. Exact optimization is NP-hard at
bandwidth two even near the identity, so unless
$\mathrm{NP}\subseteq\mathrm{ZPP}$ the polynomial dependence on $C$
cannot be replaced by dependence on encoding length, even for fixed
$H$, $\mu$, and $\sigma$. Without perturbation, messages can need
exponentially many quadratics even with local coefficients from a fixed
finite set. The polynomial upper bound has high degree; we discuss its
practical relevance.
\end{abstract}
