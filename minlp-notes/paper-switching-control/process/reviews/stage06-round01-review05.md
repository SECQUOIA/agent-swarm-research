## Required minor correction

**MINOR M1 — Parenthesize the argument of the remainder operation in the deterministic input formula.**

- **Locator:** `sections/12-computations.tex:163–165`, manuscript Section 15.3, p. 50, paragraph specifying the inputs for Table 6; compare `verification/stage06/experiments.py:193`.
- **Issue:** The printed expression is `1+((j+2)(i+3)+i^2 mod 11)`. It does not explicitly delimit whether the remainder operation applies to the entire sum or only to `i^2`. The code applies it to the entire sum. This matters for independent reproduction: at `j=2, i=0`, the implemented weight is `1+(12 mod 11)=2`, while applying the remainder only to the squared term gives `1+12+(0 mod 11)=13`.
- **Suggested correction:** Write, for example, `1+\bigl(((j+2)(i+3)+i^2)\bmod 11\bigr)`, or define the integer sum first and then take its least nonnegative remainder modulo 11. This is a notation clarification; I found no error in the implemented input, archived outputs, or matched-method comparison.
