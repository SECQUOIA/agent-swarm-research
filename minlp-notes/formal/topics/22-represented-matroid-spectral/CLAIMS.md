# Topic 22 frozen claims

Date: 2026-09-22. These 37 obligations fix the substantive source scope
before implementation. They are not a completion record. The
[source inventory](SOURCE-REVIEW.md) records the sources, permitted
equivalent construction, reuse, and verification boundaries.

The input is an explicit rational matrix `A` of size `a` by `m`, element
information matrices `Q_e`, prior `Q0`, fixed information dimension `p >= 1`,
and rational `0 < eta < 1`. Information is
`J(B) = Q0 + sum_(e in B) Q_e`. Write `q = rank(A)` for the original
matroid rank, `q'` for the optional rank after forcing owners, and `r` for
information rank. Only `p` is fixed.

| ID | Required mathematical or algorithmic conclusion |
|---|---|
| M01 | Define actual column-matroid independence and bases for the supplied rational representation; prove existence, common cardinality `q`, and the unique empty base when `q=0`. Connect every returned set to these semantics. |
| M02 | Construct exact rational row reduction or an equivalent representation procedure, preserving all column dependencies. Establish that redundant rows and nonzero denominator clearing preserve bases, with polynomial bit work when `a,q,m` grow. |
| M03 | Implement rank-preserving restriction and forced-owner feasibility. Reject filtered elements of rank less than original `q`, dependent forced owners, and owners removed by filtering. For every target base the good normalization trial passes these tests. |
| M04 | Implement the source's owner-count alternative: append a `0/1` coordinate marking `F` to original-rank profiles and retain only count `|F|`. Prove this is exactly the family of original bases within the retained elements and containing `F`. Optional sets have size `q'=q-|F|`; when `q'=0`, the only accepted base is `F`. No contraction implementation is claimed. |
| N01 | Obtain actual rational PSD factors, at most `p` positive weighted nonzero rank-one terms per element/prior, including singular and zero matrices. Retain distinct factor labels and owners, with `M <= p(m+1)`. Reuse must connect the factor producer to the original topic-22 input. |
| N02 | Enumerate independent rational factor-label subsets of every rank `1 <= r <= p`, in deterministic order, with at most `binom(M,r)` trials. Produce rational dyadic scales with `1 <= tau_i^2 w_i < 4`, without computing square roots or a maximum-volume oracle. |
| N03 | Construct `L`, `Pi`, `T`, and `K`; prove left inverse, projector, `TK=I`, `KT=Pi`, and exact rectangular reconstruction for symmetric retained matrices. Implement the range and diagonal tests and prove retained transformed entries have absolute value at most `4p`. |
| N04 | Form the distinct nonprior forced-owner set `F`, with `|F| <= r`. Handle repeated owners and prior-owned factors correctly. Every accepted lifted base has normalized information at least `I_r` and original information range exactly the trial range. |
| N05 | For every positive-information-rank target base, its actual weighted factors have a maximum-volume basis; all factor coordinates in that basis have absolute value at most one. Connect this proof-only basis to an enumerated rational label trial, including proper singular subspaces. |
| N06 | Prove every element and the prior of that target survive the trial's range and magnitude tests. Its owners are forced, independent, and retained; its filtered restriction preserves original rank. Thus every target has an accepted trial, without an assumed normalization certificate. |
| N07 | Prove PSD sums have the needed exact factor range and kernel intersection. The information-rank-zero branch tests `Q0=0` and searches zero-element columns for an original-rank base; it covers exactly all zero-information targets. Distinguish this branch from `q=0`, which returns the empty base even for nonzero prior. |
| P01 | For `h=eta/(rq)`, compute exact signed upper-triangular floors, keeping the prior exact. With `Lmax=ceil(4p/h)`, prove labels lie in `[-Lmax,Lmax]` and shifted labels in `[0,2Lmax]`. Common base cardinality makes shifted and signed profile equality equivalent; common forced elements cancel exactly, leaving optional profiles of cardinality `q'`. |
| P02 | Prove the actual Cauchy–Binet identity `det(A_ret diag(y^w_e) A_ret^T) = sum_B det((A_ret)_B)^2 y^(sum_(e in B) w_e)` with original `q` rows and the appended owner coordinate. Prove coefficients are nonnegative and positive exactly for attained original-size profiles over rational characteristic-zero arithmetic. No profile oracle or basis enumeration substitutes for the determinant algorithm. |
| P03 | Prove coordinate degree bounds: at most `2qLmax` for full-base information profiles and at most `|F|` for the owner marker. Optional information profiles have degree at most `2q'Lmax`. Define actual deterministic exact determinant evaluations on a product grid or equivalent moment curve, and recover all coefficients by implemented exact interpolation, proving uniqueness and agreement with the generating polynomial. |
| P04 | Implement one-pass deletion for each positive owner-complete target coefficient, keeping the original `q` rows throughout. Prove target feasibility persists, earlier infeasible deletions remain infeasible, and the final set is an actual original base containing `F` with exactly that profile. At most `m` deletion tests per profile suffice. |
| P05 | Return recovered bases across all accepted trials, plus the rank-zero branch when applicable. Every output is an actual original base, the output is nonempty, and every target's accepted trial returns a representative of its profile. Removing duplicate base identities is permitted. |
| P06 | Connect the semantic determinant, interpolation, deletion, owner forcing, and trial operations to one deterministic finite producer from the supplied matrices. Exponential ground-truth enumeration may be used in proof specifications or small tests, but cannot be the claimed polynomial execution. |
| S01 | Equal optional profiles give every entry difference strictly below `q'h` when `q'>0`; negative floors are included and common prior/forced terms cancel. Treat `q'=0` exactly. Derive the quadratic-form bound with the explicit factor `r q h = eta`. |
| S02 | Combine that bound with the target's proved normalized identity floor and undo the rectangular congruence. For every actual target base, one actual returned base satisfies both inequalities `(1-eta)J(B) <=PSD J(Bhat) <=PSD (1+eta)J(B)`. |
| S03 | Prove target and representative have identical kernels and ranges, including zero and singular information. The theorem requires no positive definite prior, lower eigenvalue bound, or condition-number assumption. |
| C01 | Prove at most `(2q'Lmax+1)^(r(r+1)/2)` representatives per trial and the output bound `1 + sum_(r=1..p) binom(M,r) [2q ceil(4prq/eta)+1]^(r(r+1)/2)`. Include rank-zero and empty-base cases and actual witness length at most `q`. |
| C02 | Prove polynomial encoding lengths for representation reduction, forcing/contraction, rational factors, dyadic scales, projectors, transformed matrices, floors, grid monomials, evaluated determinant matrices and coefficients, and interpolation operands. Near dependence and growing `q` are allowed. |
| C03 | Give polynomial-time exact determinant and linear-system arithmetic for the variable dimensions `q` and the interpolation grid. Account for operand bit lengths and primitive integer/rational arithmetic. A permutation determinant or an adjugate routine with factorial work does not discharge this claim at growing rank. |
| C04 | Tie preprocessing, all trials, profile recovery, deletion tests, storage, and witness production to an executed cost model. Prove polynomial Turing bit work in the complete rational input length and `1/eta` for fixed `p`, with dimension-dependent exponent allowed. A symbolic polynomial bound disconnected from the producer is insufficient. |
| O01 | For a nonnegative Loewner-monotone criterion homogeneous of positive degree `a`, selection from the produced bases inherits factor `(1-eta)^a`, subject to a suitable evaluation/comparison method. Concavity is unnecessary; monotonicity alone does not give the ratio. |
| O02 | Derive determinant factor `(1-eta)^p`, determinant-root factor `1-eta`, and D-optimality ratio `1-epsilon` at `eta=epsilon/p`, using exact rational comparison. Preserve zero-optimum and all-singular cases. |
| O03 | Derive E-optimality ratio `1-epsilon` at `eta=epsilon` with an actual exact fixed-degree algebraic comparison realization, including equal/repeated eigenvalues and polynomial bit work. All-singular feasible families have zero optimum. |
| O04 | Derive inverse-trace ratio `1/(1-eta)`, hence `1+epsilon` at `eta=epsilon/(1+epsilon)`, by actual inverse order. Detect existence of positive definite feasible information. Singular information has infinite conventional A-cost; no numeric infinite-cost ratio is asserted. |
| O05 | Prove the two common-range Moore–Penrose inverse inequalities and preservation of estimability. Transfer A-type bounds to a specified estimable contrast and nonnegative weighted contrast sums, handling zero variance without dividing by it. For bit work, contrasts and weights need encoded rational input or a specified comparison procedure. |
| O06 | Prove the same produced set remains a cover after adding any common PSD prior or applying any common possibly rectangular congruence. State the comparison assumptions for criteria selected afterward. |
| U01 | Prove rational Vandermonde columns represent uniform matroids, including growing rank and polynomial entry encoding, so fixed-cardinality experiment selection fits the actual input contract. |
| U02 | Prove direct sums of the uniform representations give partition-quota bases and retain polynomial representation encoding. |
| U03 | Prove oriented incidence representations give graphic-matroid bases, hence spanning trees in the connected case and spanning forests generally. Information remains additive by edge. |
| B01 | Verify explicit mixed-determinant cancellation and finite-field reinterpretation witnesses. They delimit the single rational representation proof; they are not hardness claims about every broader algorithm. |
| B02 | Verify the unattainable projected-profile example with scalar values `1,3`, and the interior-optimal-profile example `diag(1,3),2I,diag(3,1)` for determinant and minimum eigenvalue. Projected vertices or arbitrary integer points cannot replace attained profiles. |
| B03 | Preserve the two-sided-cover qualification: deleting dominated representatives can lose the upper guarantee, and different singular ranges cannot be substituted merely because matrices are close entrywise. Reuse existing proved witnesses where appropriate. |
| B04 | Verify the algorithmic safeguards with exact witnesses where appropriate: keeping original rank during deletion, treating positive rational coefficients as characteristic-zero values, and separating `q'=0` from a strict positive remainder bound. Record independence-oracle, finite-field, intersection, correlated-history, and priority exclusions without turning them into unproved hardness claims. |
