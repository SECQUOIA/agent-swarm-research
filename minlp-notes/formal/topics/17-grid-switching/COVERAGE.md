# Arbitrary-grid one-switch minimax and sharp grid transfer: coverage map

This map assigns every obligation of [CLAIMS.md](CLAIMS.md) to actual Lean
declarations and records every difference between the source statement and the
proved statement. Build, axiom and replay evidence is in
[VERIFICATION.md](VERIFICATION.md); the independent reviews are in
[REVIEW.md](REVIEW.md).

All declarations are in namespace `GridSwitching`; proof sources are in
[`Formal/GridSwitching`](../../Formal/GridSwitching). The package builds a new
model rather than extending the three-mode unit-grid model of
[topic 1](../01-switching-control/README.md); see that topic's README for why.

## Conventions actually implemented

- The mode count `n` and the cell count `N` are both parameters; grids are
  arbitrary strictly increasing `x_0 = 0 < ... < x_N = T`.
- Blocks `k` and switches `s` satisfy `k = s + 1`. `OPT` and `F` are indexed by
  switches; `OPTminus` and `Gminus` by blocks. Initial activation is free:
  a schedule is a word with ordered times, so constant and repeated-mode
  schedules and zero-length blocks are all admitted.
- The minimax quantifier order is supremum over inputs of infimum over
  schedules.
- **The asymmetry of `eq:grid-definitions` is preserved exactly**: `gridOPT` is
  defined for every input and its attainment theorem
  (`exists_gridOPT_eq`) assumes nothing about the input, while `gridF`
  maximizes only over grid-constant inputs.
- The two objects the sources both write `H` are separated: `gridH` is the
  two-large-modes grid quantity of `eq:grid-H`; the continuous one-switch
  minimax `H_n(T)` of Section 2 is not defined in this package.
- `0 < n` (usually `3 ≤ n`) and `0 < T` appear as explicit hypotheses where the
  sources leave them implicit. Each occurrence is recorded below.
