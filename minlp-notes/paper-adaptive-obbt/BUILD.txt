Build the anonymous manuscript from this directory with a TeX Live installation:

    latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex

Without latexmk, run these commands in order:

    pdflatex -interaction=nonstopmode -halt-on-error main.tex
    bibtex main
    pdflatex -interaction=nonstopmode -halt-on-error main.tex
    pdflatex -interaction=nonstopmode -halt-on-error main.tex

The submission archive contains the bibliography source and the formatted
bibliography. It contains every manuscript input and any local bibliography
style used for the final build. Author information is intentionally omitted.

The experimental evidence and reference implementations are supplied in the
separate reproducibility companion. Building the manuscript executes no
scientific computation or numerical experiment.
