# Software and benchmark source audit

This identified-source batch checks the software and test-set citations in the adaptive OBBT experiments. It does not make algorithmic novelty claims. The approved entries are in [`literature-software.bib`](literature-software.bib); root owns merging them into the manuscript bibliography.

The experiments record Gurobi 13, SCIP 10.0.2 through PySCIPOpt 6.2.1, SciPy 1.18.1 using HiGHS dual simplex, and a 377-instance MINLPLib screening set. The versioned software citations support identity and version statements only. The manuscript does not record a HiGHS version or a Gurobi patch version, so neither is asserted here.
