**Required finding R1-1 — minor: the main box nonemptiness criterion omits an input assumption.** In `complexity/narrative/01-model.tex:36–42`, equation `eq:main-box` requires only rational vectors `ell,u`, after which the text asserts that the balanced box is nonempty exactly when `sum ell <= 0 <= sum u`. It must additionally require `ell <= u` coordinatewise. On a connected two-vertex graph, take `ell=(1,-2)` and `u=(-1,2)`. The two sums are -1 and 1, so the stated test passes, but the first coordinate would require `1 <= b_1 <= -1`. The box is empty. Appendix A, `complexity/sections/01-preliminaries.tex:424–435`, correctly supplies `ell <= u` before the same equivalence. Add `ell <= u` to the main equation's data conditions, matching the appendix. Alternatively include it in the stated necessary-and-sufficient condition. This is minor because the main positive results use nonempty admissible domains and the included technical model already has the missing hypothesis; it does not invalidate their proofs. It is a false criterion as printed, rather than a stylistic preference.
