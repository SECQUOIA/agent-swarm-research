## Valid findings

1. **Minor: the benchmark's overall coefficient ratio is misstated.** Section 11, line 767, describes a coefficient ratio of `10^6`. In `code/potential_flow_mpd/certified_envelope_benchmarks.py`, `instance` uses base values `1` and `ratio`, then gives each edge endpoints `base` and `3*base` (lines 27–31); `run` calls `instance(15, ratio=10**6)`. Consequently both the original allowed endpoint ratio `max(upper)/min(lower)` and the reconstructed envelope coefficient ratio `max(cp+cm)/min(cp+cm)` are exactly `3000000`. I independently evaluated both as Fractions. The `10^6` is the fixture's base-scale parameter, not its overall coefficient ratio. Repair line 767 to say `an overall coefficient ratio of 3·10^6`, or explicitly identify `10^6` as the ratio between the two base scales. This does not weaken the experiment; it makes its description exact.

2. **Minor: specify rational epsilon for rational dual attainment.** In `ex:a-cert-paths`, lines 520–521 allow `0 < eps < 1` without a rationality qualification. Lines 535–547 then assert rational dual attainment, rational node potentials, and the exact upper value `1+eps`, using `lambda=1/(4L eps)`. These claims require rational epsilon. For example, `eps=sqrt(2)/10` gives irrational lambda and irrational support value, so a rational witness of the stated form cannot attain it. The geometric support interval and fixed-L asymptotics remain correct for real epsilon. Repair by starting with `rational 0 < eps < 1`, or by qualifying the rational-attainment paragraph with `If eps is rational`. The rational sequence `eps→0` still proves the stated asymptotic separation. All retained demonstrations use rational epsilon, so no experiment changes are needed.
