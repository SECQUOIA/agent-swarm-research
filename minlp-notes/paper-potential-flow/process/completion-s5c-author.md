## Proof audit and key boundaries

The scalar approximation proof starts from the actual graph formula. At a generic real graph point, some value-dependent polynomial must vanish; otherwise the formula would be locally open in two dimensions. Its primitive squarefree product over the rational function field therefore annihilates the continuous response, including exceptional specializations by continuity. Subresultants give polynomial degree and coefficient bounds for this construction. The leading value coefficient and the resultant with the value derivative form a nonzero polynomial containing all finite branch and pole parameters.

The proof computes real parts of all complex exceptional parameters, including those not on the real axis. Rational enclosures padded by a dyadic width form a union whose total length is controlled by the supplied Lipschitz constant and local error tolerance. Constants approximating actual midpoint values cover these short bands, including real branch switches and interval endpoints. Rational geometric panels on the complementary gaps stay a fixed relative distance inside complex disks without root collisions or poles. The leading coefficient has an explicit lower bound from root distances. The ordinary Cauchy polynomial-root bound then gives a complex branch magnitude whose logarithm is polynomial in the input and accuracy bits. No lower bound on a nonzero physical flow is used.

The final construction interpolates rational approximations to the response at equally spaced rational nodes. It does not compute Taylor coefficients in a joined algebraic field. The manuscript proves the contour interpolation remainder and an explicit Lagrange-basis bound. Choosing the least interpolation degree meeting the geometric error bound and choosing node accuracy `eta/[8(2q)^q]` makes both the interpolation error and its perturbation small. The node accuracy requires only polynomially many bits. Expanded rational coefficients have polynomial encoding because there are polynomially many products of polynomially many rational factors. Every actual node value is isolated independently from the original graph formula.

The scalar summation theorem takes a common rational interval partition and adds the rational polynomial surrogates. It optimizes their maxima by ordinary univariate real-algebraic methods and rounds an algebraic argument using the actual sum's Lipschitz bound. The error ledger leaves ample room: local summation error at most `eps/16`, a surrogate enclosing interval of width `eps/8`, sample deficit at most `eps/16`, and rounding loss at most `eps/4`. The returned true optimum interval has width at most `eps/4`, and the physical argument loss is below the requested tolerance.

The network local-value graph uses only a fixed number of nominations, circulations, and value variables. One local weighted value uses one objective row even when its objective support is large. The accepted box-leaf lemma eliminates all independent coefficient coordinates. The maximum graph adds one quantified competing value; it does not introduce a variable per edge. Exact local values remain separate across blocks. In the line theorem, the rational nomination argument is selected first, then every block is reoptimized at that same rational argument. The original coefficient intervals are rounded with the accepted global coefficient Lipschitz estimate. This avoids preserving artificial chart membership under rounding.

For the fixed-law dense polynomial corollary, all local edge-law breakpoints are pulled back to affine hyperplanes in the fixed circulation/parameter dimension. Cycle and value equations have growing but densely encoded polynomial degree. Their quantifier eliminations are still polynomial in that degree. Absolute coefficient sums bound values and derivatives on the global flow box. The acyclic difference-flow estimate needs only strict monotonicity, so these derivative bounds supply the needed nomination Lipschitz constants. The corollary does not assert a joint growing-degree coefficient-uncertainty extension.

The hybrid theorem retains every exceptional circulation, whose total number is fixed. It combines all exceptional cycle equations and exactly one total weighted value row in one parametric box LP. This addresses the potentially unbounded number of uncertain exceptional-edge coefficients without enlarging the core. The exact box projection is computed with quadratic input data before the growing-degree cactus approximation is introduced. The remaining cactus surrogate is optimized in the fixed variables `(z,q,v)`. The accepted box-leaf recovery construction works at every feasible algebraic core/value, not only at the box lemma's own maximum. It supplies the exceptional original coordinates; each cycle profile is recovered in its separate local extension. Rational recovery uses the original polytope and coefficient boxes and the global physical continuity estimate.

The unresolved interface is restricted precisely to several shared nomination parameters with an unrestricted number of higher-rank blocks. Each summand has a polynomial-size bounded-degree rational graph and an explicit polynomial-bit Lipschitz bound. Neither a general shared-coordinate rational approximation compiler nor another accuracy-bit optimizer for that whole interface is claimed. Direct QE with one state per block loses fixed dimension, and a Lipschitz grid loses accuracy-bit dependence. Those are limitations of particular arguments, not impossibility or hardness results. The manuscript does not imply that additive optimization requires an exact SRS solution.

## Verification and preservation

- The discriminant of the genuinely implicit response `y^5+y=t`, its complex critical real parts, and primitive/squarefree extraction for a repeated product with parameter content.
- A real branch switch `abs(t-1/3)`.
- The positive root of `(t-1/2)^2+2^-16`, whose complex branch parameters have imaginary distance `2^-8` from the real axis.
- The rational response `1/(t+2^-6)`, with an external pole and a large Lipschitz bound.

It verifies exact interpolation identities and rational contour-error bounds.
