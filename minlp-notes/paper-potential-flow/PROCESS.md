The user's completion instruction supersedes the old P0 scaffold and two-paper allocation. The authoritative stage definitions and adjudications are recorded in [completion-plan.md](process/completion-plan.md). This index does not accept a stage or replace lead adjudication.

Every stage requires an author, five independent reviewers, lead adjudication, and a different correction agent to fix every valid issue, including minor issues. A valid major issue triggers another five-reviewer round after correction. Stage 7 completed this process for the whole manuscript; the [final adjudication](process/completion-s7-adjudication.md) records acceptance and verification. Review and correction do not authorize external submission, and no external submission is part of this work.

The main paper provides model/output definitions, principal statements, proof ideas, original vector diagrams, examples, literature comparison and synthesis. All accepted technical sections 01–11 are included in dependency order as appendices. The one-line bounded-block weighted theorem and fixed-total-noncactus-rank hybrid theorem are completed; only the precisely stated unrestricted several-parameter higher-block sum remains outside the proved algorithms.

Build and exact replay use [the A-only delivery scripts](reproducibility/README.md). A clean gate requires no LaTeX errors, undefined references or citations, duplicate labels, or overfull boxes. The standalone source archive must build and replay outside the repository. It contains selected transitive code dependencies and rational data, but no other paper, managed literature PDFs, original INP file, or internal review report. The previous two-paper build CLI is not the Paper A completion gate.

The initial uncommitted manuscript developments are preserved. Research notes, promoted results, managed literature, existing numerical code and saved original data remain unchanged. Internal review reports are evidence of the process, not journal peer review or universal mathematical tests.
