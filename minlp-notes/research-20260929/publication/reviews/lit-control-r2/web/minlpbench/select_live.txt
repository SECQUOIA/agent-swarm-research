1. Select all instances that are marked as "solvable" from MINLPLib (as of 2018-12-14):
   Consider only instances where at least 2 solvers reported a dual bound
   that has a relative gap of at most 0.0001 to the best known primal
   bound (best objective value of stored feasible solution,
   absolute feasibility tolerance is 1e-6).

2. Run the 5 global MINLP solvers from GAMS 25.2(alpha) (ANTIGONE, BARON,
   COUENNE, LINDO, SCIP) with a short timelimit (65 seconds), 20GB memlimit.

3. Check solver outcome. Mark a run as failed, if
   - reported solution is not feasible (absolute feasibility tolerance 1e-4)
   - reported dual bound is not consistent with best known primal bound (relative tolerance 1e-4)
   - reported primal bound is not consistent with trusted dual bound (relative tolerance 1e-4)
     (this should not happen, as we check for feasibility before)
   - reported gap is negative (< -1e-4)
   - no solving time reported
   
4. Exclude instances that are trivial to solve by at least one solver:
   - not failed, and
   - gap < 1.1e-4, and
   - time < 61s
   Exclude instances that cannot be handled by some solver (unsupported
   functions or variable types).

5. Manually reduce dominance of models with many instances.
