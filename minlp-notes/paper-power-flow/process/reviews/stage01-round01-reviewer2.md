## Required minor corrections

1. **Bijection direction changes without an explicit definition.** In `sections/02-resistive.tex:207–209`, the proposition calls its map “the bijection of Lemma” and then says that its inverse is the coordinate projection. The lemma at lines 163–165 explicitly names restriction from the network feasible set to `S_Phi` as its bijection. That restriction is already the projection. The proposition's proof correctly studies the opposite map, the extension from source solutions to network voltages. Define that direction explicitly in the proposition, for example: “The extension map from `S_Phi` to the network feasible voltage set is a homeomorphism ... Its inverse is ...”. This is a local notation issue; both maps and all substantive claims are proved correctly.

2. **The abstract omits certificate verifiability.** In `main.tex:24–25`, “polynomial certificates for exact feasibility would imply NP = exists-R” should say “polynomial-size certificates verifiable in deterministic polynomial time” (or equally precise compact wording). Polynomial length alone is not the NP condition. The corollary and proof already include the correct qualification, so this does not undermine the theorem.
