Review of nuclear-global/assessment.md (feasibility assessment for the open nuclear* instances)
Date: 2026-09-23. Reviewer: independent skeptical review (fresh agent). No author code was imported;
all checks below use the reviewer's own parser and scripts in nuclear-global/code/review/.

SUMMARY
The mathematics is sound. The power-variable reformulation is exact. B1, B2, B3 (IEP) and B4 are valid
upper bounds for the model as written. The node and pattern counts are correct. The reviewer reproduced
the root B3/B2 values independently and CERTIFIED them in exact rational arithmetic for all seven F1
instances (va-vf, 14). The certified values agree with the author's table to within 1.2e-6, but four
of the author's 6-decimal entries are slightly below what can be certified and must be rounded up.
Independent Gurobi runs match the root B4 value for nuclearva (1.160711) and the leaf B4 values
(floating point; B4 is not certified).
Fixes are needed in five places:
  (a) Assumption U, as stated, is too weak for the enumeration argument.
  (b) "A fixed pattern has no continuous freedom" is stated as a fact. It depends on U.
  (c) "No subtree can be pruned at any depth" is false: IEP proves some fresh-fuel placements
      infeasible at depth 3.
  (d) The certification status and rounding of the new bounds need restating.
  (e) Several small factual items (stored primal precision, sampled contraction maximum, timing).
No finding changes the headline verdict: no-go for branch and bound, and enumeration of va-vf is
conditional on an unproven uniqueness result.

(1) POWER-VARIABLE REFORMULATION AND TIE ROWS -- VERDICT: CORRECT (two small fixes)

- Proposition 1 is correct.
  * lam_t > 0: if lam_t = 0, then G(phi o k) = 0. Every column of an irreducible G with N >= 2 has
    a positive entry, and phi, k >= 0, so phi o k = 0. This contradicts the normalization row.
  * Forward direction: multiply eigen row i by k_i.
  * Converse: phi := Gp/lam >= 0, and (R4) gives phi_i k_i = p_i.
  * Injectivity: phi is forced by the eigen rows.
  * (R5) is exactly phi >= phi_lb.
- Variable bounds were confirmed from the files.
  * phi, k, lam have lower bound 0 and upper bound +INF in F1.
  * In F2/F3 (14a, 14b, 25a, 49b, 10a checked), phi >= phi_lb > 0 and k >= 0.12.
  * No phi has a finite upper bound, so "(R5) has no upper counterpart" is correct.
- Numerical check at the seven stored primal points: R1-R4 hold to <= 9.6e-25, and phi = Gp/lam holds
  to <= 1.1e-25. These residuals come from the 25-digit storage (see (5)).
- Tie rows: confirmed.
  * va-vf contain exactly 24 rows y_{i,g} - y_{j,g} = 0, for the node pairs (1,7) and (11,14) (1-based)
    and all 12 types.
  * V = 1/2 on these four nodes and 1 on the other ten.
  * Because every type row has weight 1, each type occupies exactly one of the 12 slots
    (10 full nodes plus 2 tied pairs).
Fixes:
- F1.1 In (R4), write "lam_t >= eps" or state explicitly that the strict inequality lam_t > 0 is part
  of the reformulated feasible set. Without it, lam_t = 0 is feasible in the reformulation whenever
  some k_i = 0. A solver model must impose lam_t > 0 through a bound, or rely on k > 0.
- F1.2 Section 2, step 2: p_t is the Perron vector of diag(k_t) G, not of G diag(k_t). The two
  matrices are similar and have the same spectral radius, so this is notation only.

(4) "A FIXED PATTERN HAS NO CONTINUOUS FREEDOM" AND UNIQUENESS -- VERDICT: REDUCTION CORRECT;
HEADING OVERCLAIMS; ASSUMPTION U TOO WEAK AS STATED

- Steps 1-3 are correct.
  * (K+) gives k > 0.
  * The Perron vector is unique at each t.
  * The reload is affine, with R >= 0 and R^4 = 0.
  * Rows of fresh nodes are zero; the other rows are V-weighted means.
  * 183 equations in 183 unknowns: 84 p + 84 k + 6 lam + 9 kappa.
- These steps show only that the feasible set of a pattern equals the peaking-feasible fixed points of
  Phi. A square analytic system can have several isolated solutions or a continuum. "No continuous
  freedom" therefore holds only under U.
- U is clearly labeled unproven in Sections 2 and 6 and in the Summary. Good.
Fixes:
- F4.1 Rename the heading to "A fixed F1 pattern reduces to a fixed-point equation in k_1". Move
  "no continuous freedom" into U.
- F4.2 U as stated ("at most one PEAKING-FEASIBLE fixed point") does not support the enumeration.
  * 78% of the va patterns have a computed fixed point that violates peaking.
  * U allows such a pattern to have a second fixed point that satisfies peaking. That point would be
    feasible and would be missed.
  * The a-priori box B from (K+) does not help. A peaking-violating fixed point need not lie in B,
    and Phi need not map B into itself.
  * State U as: "Phi has at most one fixed point in Omega = {k_1 : the cycle from k_1 keeps k_t > 0}".
    Omega is the domain where Phi is defined and contains every feasible point.
  * Alternatively, certify infeasible patterns separately, for example with the IEP emptiness test
    (see (5b)).
  * The contraction route in Section 4 needs its domain chosen so that Phi^4 maps it into itself and
    it contains both the computed and any feasible fixed point. Say so.
- F4.3 "Sampled contraction of Phi^4 ... is at most 0.53 (va)": this is a sample maximum, not a
  bound. The reviewer found 0.578 on one of 6 random va patterns (10 random box points each;
  runs/review/contraction_va.txt). Write "the largest sampled value was 0.53 (va) ...".
  The local rho(dPhi) = 0.41-0.55 agrees with 0.33-0.61.
- F4.4 Minor: the Birkhoff-Hopf coefficient of G^5 for nuclear14 computes to 1 - O(1e-8), not 1 to
  machine precision (va: 1 - 4.1e-5, confirmed). |lambda_2|/lambda_1: 0.9410 and 0.9655, confirmed.
