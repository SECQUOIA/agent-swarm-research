1. Validity of the added constraints

What is actually computed. The "valid" numbers come from gridrelax.py ... outer. This is an LP, not the
SOC extended formulation or the exact hull. For each pool-output pair (l,j) it adds a Balas disjunctive
formulation over x = y_lj in [0, XU], split into intervals [x_g, x_{g+1}]. Each piece is the block set
with w_i = x q_i replaced by McCormick rows for x in [x_g, x_{g+1}] and q_i in [0, qU]. The block set is:
  - q in the simplex; sum_i w_i = x;
  - bypass aggregates v_b >= 0, with x + sum_b v_b <= C_j;
  - the output's quality rows sum_i g_ij w_i + sum_b g_bj v_b <= 0.
The master coordinates are y_lj, q_il, w_ilj and v_b = z_bj + sum_{l' != l} w_{b l' j}.
The SOC/"finite union of pieces" hull statements in Section 3 are not used by these bounds. The bound is
therefore that of an outer approximation of the hull. It is weaker than the exact-hull value but still
valid. (The inner grid estimates -93317.03 and -45038.59 are not bounds.)

Argument. Take any feasible point of the original pq model and fix (l,j). Its projection satisfies every
row of the block set:
  - simplex: an original row;
  - sum_i w_ilj = y_lj: w_ilj = q_il * y_lj and sum_i q_il = 1;
  - the quality rows: each is an original row, rewritten after grouping bypass flows by input. This is
    exact because every quality coefficient depends only on (input, output). spp.py asserts this, and it
    was rechecked here: the quality rows are reproduced identically.
    Every flow into j other than via l is in some v_b. An omitted flow with a negative coefficient would
    make the block row invalid, so this matters; it holds.
  - x + sum v_b <= C_j: the original output-capacity row;
  - x <= XU: the author's XU = ybound(l,j) equals the OSiL bound on y_lj for all 115 and 234 pairs.
On the interval containing y_lj, the four McCormick inequalities are the products of nonnegative bound
factors, so they hold exactly. The lift that puts lambda = 1 on that piece and 0 on the others satisfies
the homogenized system. Every piece's McCormick rows are valid on its interval and the pieces cover
[0, XU], so the disjunction is a relaxation.

The pq layer adds only valid rows:
  - McCormick of w = q y with OSiL bounds;
  - sum_i w_ilj = y_lj;
  - sum_j w_ilj <= C_l q_il, which is q_il times the pool-capacity row.

Numerical test. Every point is lifted into the author's outer LP (G=40, the grid of the sppc0 run) and
into the independent LP, and every row and bound is evaluated. The points are:
  - MINLPLib solutions: sppb0pq p1-p2 and sppc0pq p1-p6;
  - 20 random starts per instance, each with 6 alternating LP steps (fix q, then fix y), using the true
    objective or random objectives;
  - 4 local-search steps from each MINLPLib point.
Each point is feasible in the original model to at most 2.7e-9.
   sppb0pq: 130 points; worst row violation, author LP 2.1e-10, independent LP 2.1e-10.
   sppc0pq: 150 points; worst row violation, author LP 5.7e-10, independent LP 5.7e-10.
   These are the points' own tolerance levels. No constraint cuts off a feasible point.
   (A first run showed a spurious violation of 145. The cause was a lift bug in the checker: y = -5e-12
   was assigned to the last piece. It was fixed and rerun.)

3. Independent rebuild and safe bound (indep_bound.py)
   The LP is built directly from OSiL decimal data and does not use spp.py, instance.py or gridrelax.py.
   Its rows are:
     - all original linear rows and bounds;
     - McCormick of every bilinear row;
     - sum_i w = y, and the q-times-pool-capacity rows;
     - for each y_lj, the Balas outer disjunction over the same x grid (G=40 -> 46 points, 45 intervals).
   Block rows are all original rows whose support lies in the output's flows. Other flows are aggregated
   by identical coefficient vectors, and every piece variable has a finite, valid upper bound.
   The LP is solved with Gurobi barrier, no crossover, BarConvTol 1e-10. (Crossover stalled on sppc0.)

   Safe bound (Neumaier-Shcherbina):
     - take the row duals and set wrong-signed values to 0;
     - compute d = c - A^T y with a rigorous floating-point error bound. The bound includes 2^-52 relative
       uncertainty of every coefficient and right-hand side against its decimal value;
     - bound = b^T y + sum_j min over the box of d_j x_j, with directed error terms and correctly
       rounded sums (math.fsum).
   All variable bounds are exactly representable, which is asserted in the code. Grid products are
   asserted exact.
   Sanity test on sppb0 with a coarse grid: the safe value is at most the exact-rational evaluation of the
   same certificate, for exact and for noisy duals (noise 0, 1e-6, 1e-3).

   instance  grid  LP rows x cols        LP value         SAFE BOUND        author valid  author inner
   sppb0pq   46    671718 x 263842       -45046.101108    -45046.1011081    -45047.42     -45038.59
   sppc0pq   46    1713394 x 728587      -93325.220789    -93325.2207955    -93442.92     -93317.03
   The safe correction is below 1e-5. The independent LP is slightly stronger than the author's. This
   plausibly comes from the extra valid bounds: the OSiL w bounds, and the bounds on the aggregated bypass
   flows in each piece.
