# Nonlinear input-rank refinement

The independently reviewed theorem is now in
[results/quadratic-nonlinear-input-rank-precision.md](../results/quadratic-nonlinear-input-rank-precision.md).
It gives a polynomial rational MILP within additive `O(r log(r+1))`
of the minimum convex-lift integer count, where `r` is the rank of the
stacked Hessians. Both independent reviews, source audit, and exact
rational checks are linked there.
