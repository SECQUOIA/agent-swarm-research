# Oracle error-body curvature-rank precision

Promoted after independent full proof audits, separate oracle audits, and a
focused primary-source assessment. See
[the complete theorem](../results/convex-vector-oracle-curvature-rank-precision.md):
finite overhead `ceil(log2(8r^2-1))` and polynomial rational overhead
`17+2ceil(log2 r)` for one-input convex vectors with arbitrary unconditional
strong-oracle error bodies. The final MILP uses an explicit inner parallelotope.
