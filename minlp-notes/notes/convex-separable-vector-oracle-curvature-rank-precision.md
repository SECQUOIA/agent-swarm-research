# Separable convex vectors with oracle error budgets

Promoted after two independent proof audits and a focused source assessment.
See [the complete theorem](../results/convex-separable-vector-oracle-curvature-rank-precision.md):
finite overhead `8n+2nceil(log2 r)` and polynomial rational overhead
`21n+2nceil(log2 r)` for arbitrary unconditional strong-oracle budgets.
The image and positive-polar basis are shared across every input coordinate.
