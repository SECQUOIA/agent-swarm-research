# Parallel-path network investigation

The completed extension is maintained in
[the standalone result](../results/network-simplex-parallel-path-hull.md). It allows
an arbitrary number of internally disjoint paths per block, gives explicit subset
cuts and unit flow/product coefficient inequalities, and separates them through
classical capacitated transportation. Both independent audits pass.

The source foundations and exact limits on novelty, graph scope, complexity, and
output size are recorded in the result.
