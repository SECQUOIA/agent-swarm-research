# Block PSD quadratic precision

The independently reviewed theorem is now in
[results/block-psd-quadratic-precision.md](../results/block-psd-quadratic-precision.md).
It gives additive overhead `O(sum_b r_b log(r_b+1))`, where each `r_b`
is the common nonlinear input rank inside an original coordinate block.
Two proof audits, source review, and 36 exact checks are linked there.
