# Row hulls with bilinear items: a compact exact form and a negative pilot

Date: 2026-09-21. Status: exploratory note by the root agent; brute-force checks
only, no independent review, no literature search beyond the sources of
[the row-hull note](../results/row-hull-separable-concave.md). Code:
`code/row_hull_bilinear/`.

## Observation (item sets with concave directional value functions)

Let item `i` have a row variable `x_i in [0, w_i]` and private variables `u_i`
with `(x_i, u_i) in G_i` compact, and let the items be coupled only by
`sum_i x_i = B`. For a direction `(pi, c)` put
`psi_i(x) = pi_i x + min{ c_i u : (x, u) in G_i }`. If every `psi_i` is concave
on `[0, w_i]` for every direction, a linear function attains its minimum over
the coupled set at a point whose `x` is a vertex of the row polytope, so the
joint hull is generated by row vertices `(S, j, r)` combined with extreme points
of the sections `G_i(0)`, `G_i(w_i)`, `G_j(r)`. Examples: epigraphs of concave
terms (the row-hull note), fixed-charge indicators (`psi` is a fixed-charge
function), and bilinear terms `t_i = x_i y_i` with a private factor
`y_i in [0,1]` (`psi_i(x) = pi x + min{0, mu + omega x}` is the minimum of two
linear functions). Pricing in the separation scheme of the row-hull note is
unchanged except that the concave residual function depends on the duals.

For equal widths `w` and `B = k w + r`, the generators are the integer points of
a state polytope: item `i` is in exactly one state among
`{zero, full, residual} x ext(section)`, exactly `k` items are full and exactly
one is residual. Each column of that system has one entry in the item rows and
at most one in the two cardinality rows, so it is totally unimodular and the
state form is an exact extended formulation. For bilinear items it has `6n`
variables:

```
x_i = w (s_F0 + s_F1) + r (s_R0 + s_R1),   y_i = s_Z1 + s_F1 + s_R1,   t_i = w s_F1 + r s_R1.
```

Check (`proto.py`, 240 random instances with `n <= 6`, random linear objectives
in `(x, y, t)`): the state form equals the value over the enumerated generators
(vertex enumeration, which presupposes the concavity argument above) in all
cases, and the independent review confirmed it against the nonconvex global
optimum (Gurobi, gap `1e-9`) on 60 random instances;
McCormick plus the row has a gap in 64 cases; McCormick plus the level-1 RLT
products of the row with every `y_k` (`n^2` extra variables) has a gap in 1 case.

## Negative pilot

Two model families with exact demands and unit arc capacities:

- `blend.py`: sources with purchasable quality `y_i`, arcs `x_ij`, products with
  minimum quality. The McCormick relaxation is already tight (root gap 0 on 3 of
  4 instances, solved at the root), so nothing can be gained.
- `pool.py`: standard pooling in the quality formulation (4 sources, 5 pools, 6
  products, 4 seeds). The root gap is 0–0.24%; the state form of the product
  rows leaves the root bound unchanged on every instance, alone and on top of
  the `pq` rows, and does not reduce Gurobi's nodes.

The strengthening exists as a polyhedral fact but was not hit by the objective
and constraint structure of these models. No further work is planned here.
