# Superseded extension evidence

`pre_lattice/` preserves the first ten-configuration run after the original
module readiness signals. A later requested polynomial feature added an
integer-value lattice stopping certificate. The final suite reruns those same
ten inputs and adds one configuration exercising that feature.

The archived artifacts remain reproducible and are excluded from the final
completion benchmark totals. No input or failed outcome was removed in response
to the first run's results.
