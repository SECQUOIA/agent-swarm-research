The companion results build on the same certificate discipline: verify
tractable reductions or local recourse, use corrected sparse tables for the
remaining search, and keep exact-output arguments separate from approximate
global bounds. The report provides the main mathematical chain in one
place while retaining precise links for longer supporting algorithms.
