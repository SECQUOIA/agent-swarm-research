1. **S1-R4-01 — Minor: restrict the completion claim to locally observed labels.** Location: `sections/00-introduction.tex:63–65`, especially “recover all state products.” Proposition 4.6 (`sections/02-compression.tex:314` onward) fixes a block and a label in `J_B`: its minimum reconstructs that observed label's entire state circulation. Summing these minima reconstructs the products for labels observed in their respective blocks. It does not uniquely reconstruct every individual state that was merged because it was locally unobserved. The latter states can be assigned a feasible proportional refinement, but that is a choice of lift rather than recovery of uniquely determined missing products.

   A concrete distinction survives at positive weights and away from capacity degeneracy. Take a directed three-cycle with unit capacities, zero balances, two explicit labels, `y_1=y_2=1/4`, and aggregate flow `x_e=1/2` on every arc. Observe only `z_(e,1)=1/10` on one arc. The only locally observed label has an unobserved two-edge tree, so the displayed sum of residual ranks is zero. Two valid disaggregations have constant state flows `(f^0,f^1,f^2)=(1/4,1/10,3/20)` and `(1/5,1/10,1/5)` on every arc. Both obey all scaled balances, capacities, aggregate equations, and the observation, but label 2's missing product coordinates differ. Thus the zero completion count does not determine “all state products” in the ordinary unrestricted reading of that phrase.

   Repair: say “recover all state products for each label observed in a block,” or “recover each locally observed state circulation.” If desired, add that merged states admit explicit proportional refinement. This is minor because the formal proposition already has the correct scope; no theorem or construction needs to change. Exact executable evidence is in `stage1-review4-evidence/completion_scope.py` and passes using rational arithmetic.

2. **S1-R4-02 — Minor: correct subject–verb agreement in the closest-predecessor attribution.** Location: `sections/01-foundations.tex:106`. With `\citet`, the compiled sentence reads “Khademnia and Davarnia [15, Example 2] already exhibits …”. The grammatical subject is the two authors, so use “exhibit.” Alternatively, make “Example 2 of …” the explicit singular subject. This is a copyediting defect only. The underlying claim is supported by the primary paper: Example 2 assigns weight two to one lower-bound constraint and establishes a nonbinary dual extreme point.

An optional exposition suggestion, separate from the findings: the abstract's residual-coordinate sentence has several nested qualifications (“each independent cycle in each unobserved subgraph for a label observed in a block”). A reader can understand the precise statement after the introduction, but a short two-sentence description would make the abstract easier to read independently. For example, introduce local merging and then describe one coordinate per independent cycle of each retained label's unobserved subgraph. Preserve the locally observed-label qualification; simplifying it away would repeat S1-R4-01. I do not regard the current sentence's density as an acceptance-blocking defect.
