\title{Structured bilevel optimization with many follower variables:\\
Global responses, accuracy, and structural boundaries}
\author{}
\date{}
\begin{document}
\maketitle
\begin{abstract}
We study continuous bilevel optimization in which many local follower variables
interact through a fixed number of shared quantities. For positive-definite
quadratic blocks of fixed size, we construct a fixed-dimensional description
of every global follower response, allowing polynomial and possibly nonconvex
aggregate costs. With fixed leader, block, resource and aggregate dimensions,
this gives exact algorithms polynomial in rational input length and numerical
polynomial degree. They handle polynomial upper data, optimistic and universally
feasible pessimistic selection and moving constraint normals, and decide
whether the optimum is attained. Cost-near-optimal robustness remains tractable when each upper
criterion uses a fixed number of affine measurements. For strictly convex
polynomial local costs and a convex aggregate, a different construction returns
rational leaders with global additive error $2^{-B}$ in time polynomial in
input length, numerical degree and $B$. It includes an effective sharp
$1/P$ response modulus, where $P$ is the largest marginal degree, and precise
conditions for exact upper feasibility. Hardness with dense near-identity
Hessians and path-coupled models identifies limits of these guarantees.
Exact scalar implementations retain original nonconvex contacts and distinguish
an attained optimum from an unattained supremum. Reproducible comparisons
include an independent original-coordinate baseline and the full cost of
certified dense screening.
\end{abstract}
\noindent\textbf{Keywords:} bilevel optimization; global optimization;
parametric quadratic programming; separable optimization; bit complexity;
near-optimal robustness.
