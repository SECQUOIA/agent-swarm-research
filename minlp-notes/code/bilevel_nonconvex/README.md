# Exact nonconvex aggregate tariff solver

This directory implements a scalar-leader specialization of the repository's
fixed-aggregate theorem. The follower has box constraints and objective

```
sum_i (d_i*z_i^2/2+c_i*z_i) - h*(u^T*z)^2/2 + gamma*x*(u^T*z).
```

Positive local coefficients `d_i` are required, but the complete follower
Hessian can be indefinite. Aggregate weights can have either sign or be zero.
The leader maximizes `x*(u^T*z)` with affine upper constraints. Inputs must
be rational, supplied as integers, rational strings, or exact rational objects;
floating-point inputs are rejected. `gamma` must be nonzero and `h>=0`.

See the [algorithm and proof](../../notes/bilevel-nonconvex-scalar-algorithm.md),
[source positioning](../../notes/bilevel-nonconvex-source-positioning.md),
and [computational report](../../notes/bilevel-nonconvex-computation.md).
This is an exact reference implementation, not a general bilevel solver or a
claim of superiority over production global solvers.

## Usage

The solver requires Python and SymPy; the verified environment uses Python
3.12.14 and SymPy 1.14. Run from this directory, or add it to the import path:

```python
from scalar_solver import Instance, Constraint, build_atlas, optimize_tariff

instance = Instance(
    d=(1, 1), c=(-1, '-1/2'), u=(1, 1),
    lower=(0, 0), upper=(1, 1), h='3/5', gamma=1,
    x_lower=0, x_upper=1,
)
atlas = build_atlas(instance)
capacity = [Constraint(a=0, b=(1, 1), rhs=1)]
optimistic = optimize_tariff(atlas, capacity, semantics='optimistic')
pessimistic = optimize_tariff(atlas, capacity, semantics='pessimistic')
print(optimistic)
print(pessimistic)
```

The optimistic solution has `x=17/20`, aggregate `w=3/8`, revenue `51/160`,
and `attained=True`. The pessimistic supremum is also `51/160`, but is
unattained: at the limiting tariff a second global follower response violates
the capacity. The result then supplies `limit_x` and `limit_w`, with optimizer
fields left empty. `None` means infeasibility.

Pessimistic semantics here require **every** globally optimal follower response
to satisfy all upper constraints, then use the least revenue among them.
Optimistic semantics permit the leader to select a feasible global response.
Flat response intervals and all global ties are retained explicitly.

## Verification and experiments

From the repository root:

```bash
python code/bilevel_nonconvex/check_scalar_examples.py
python code/bilevel_nonconvex/review_one.py
python code/bilevel_nonconvex/review_two.py
python code/bilevel_nonconvex/benchmarks.py
```

The two review scripts were written by independent reviewers. The benchmark
uses an independent original-coordinate active-face enumerator for small
followers and records repeated timings. Its local-solver diagnostic also
requires NumPy and SciPy. Saved results are in [benchmarks.json](benchmarks.json).
The earlier all-pairwise implementation's measurements are preserved in
[benchmarks_pairwise_baseline.json](benchmarks_pairwise_baseline.json).
They are historical measurements, not results regenerated by the current code.

`plot_contact_example.py` requires NumPy and Matplotlib and generates PDF,
SVG, and PNG illustrations in `figures/`. It illustrates why convexifying
the follower can preserve optimal values while inventing feasible upper-level
choices. It is separate from the verification scripts.

All mathematical complexity claims concern the stated rational input model.
The implementation uses a simple incremental envelope with a conservative
cubic arithmetic bound; exact symbolic processing limits practical scale.
The full theorem's arbitrary polynomial aggregate, multiple leaders, shared
resource rows, and moving constraints are outside this executable subset.
