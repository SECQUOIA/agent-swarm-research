## Independent finite verification

Before adopting any enumeration result, I read `code/mccormick_degeneracy/kn_pm1_ratio.py`, reviewer 11's `check_complete_signings.py` and witness JSON, and the manuscript's center/induced-face identities. The original code enumerates all signings, computes integer cut weights, then ranks floating-point ratios. Reviewer 11 uses switching and integer matrix products to enumerate quadratic values. The new checker uses a third implementation: exact integer cut masks and population counts, followed by exact `Fraction` ratios. No floating-point comparisons establish the new table.

The switching identity is Q_(a switched by t)(s) = Q_a(t*s). Choosing t0 = 1 and tj = a0j fixes the root star positive. The residual signings therefore number 2^((n-1)(n-2)/2), and no switching information is lost. Enumerating the 2^(n-1) cuts with vertex zero on one side covers every cut up to complementation. A cut's signed weight is its number of crossing edges minus twice its number of crossing negative edges. These facts justify the complete finite search, rather than merely checking its attaining examples.

I reran the original full-signing script in the `minlp-notes` environment and reran reviewer 11's `check(n)` function without its output-writing main block. I extracted and executed the verbatim program from the final appendix source; it returned `[1, 2, 4, 4, 5, 8]` for K2–K7. The new witness checker separately evaluates Q on every induced face. These finite computations establish only the specified finite full-signing results. The equality F_n = max_(2 <= k <= n) M_k is proved analytically using restriction and extension of full signings.
