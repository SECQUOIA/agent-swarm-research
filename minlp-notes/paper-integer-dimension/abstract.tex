\begin{abstract}
We study the minimum number of integer variables that a convex
mixed-integer lift needs to approximate a nonlinear graph, and compare
it with the minimum number of binaries in a linear lift. The projection
must contain the graph and stay within a prescribed vertical error;
the finite continuous dimension, real coefficients and integer
ranges are unrestricted. For a fixed quadratic system on a
full-dimensional box in $\mathbb R^n$, both minima equal half the
noncommutative rank of the Hessian space times $\log_2(1/\varepsilon)$,
up to an additive constant; this joint invariant can exceed the Hessian
rank of every scalar combination. At finite accuracy, a
covariance determinant determines both minima within $O(n\log(n+1))$,
uniformly in coefficients, tolerances and output count, and a rational
MILP within this bound is constructible in polynomial time. Unless
$P=NP$, for no fixed $\delta>0$ can a polynomial-time algorithm always
construct a formulation within an additive $O(n^{1-\delta})$ of the
minimum. For continuous convex functions on an interval, binary linear
lifts need at most two more integer variables than arbitrary convex
lifts; for dense rational convex polynomials, a rational MILP within
eleven binaries of the minimum is constructible in polynomial time. For
several convex outputs of one input with box error and curvature rank
$r$, binary linear lifts need $O(1+\log r)$ more integer variables, and
polynomial-time constructions for dense rational data achieve this
order. Examples give exact binary/general-integer separations and root
graphs $x^{1/D}$ that four binaries approximate at fixed error but whose
rational MILP encodings are exponentially longer than mixed-integer
second-order cone encodings.
\end{abstract}
