## 1. Setting and notation

**Domain.** `P = {x ∈ R^d : a_i^T x ≤ b_i, i = 1..m}` with `a_i ∈ Q^d` and
`b_i ∈ Q`. Box rows are included among the `m` rows, so `P` is **bounded**.
`P` may be empty. Equalities are given as two opposite inequalities. Zero
rows (`a_i = 0`), duplicate rows, positively scaled copies, and redundant rows
are allowed. Write `A` for the `m × d` matrix with rows `a_i^T`. For
`S ⊆ [m]`, `A_S` and `b_S` denote the corresponding rows.

**Objective.** `q(x) = ½ x^T H x + c^T x + c_0` with `H = H^T ∈ Q^{d×d}`,
`c ∈ Q^d`, `c_0 ∈ Q`. In monomial form
`q = c_0 + Σ_j c_j x_j + Σ_{i≤j} Q_ij x_i x_j`, with `H_ii = 2Q_ii` and
`H_ij = H_ji = Q_ij` for `i<j`. `H` may be indefinite, singular, or zero.
The gradient is `∇q(x) = Hx + c`.

**Bordered systems.** For `S ⊆ [m]` with `|S| = k`, put `n = d + k` and

```
K_S = [ H    A_S^T ]      r_S = [ -c  ]
      [ A_S  0     ],           [ b_S ] ,
```

so `K_S (x; λ) = r_S` means `Hx + c + A_S^T λ = 0` and `A_S x = b_S`. With
this sign convention, KKT multipliers for `min q s.t. Ax ≤ b` satisfy `λ ≥ 0`.

**Candidate set.** `𝒞 = { x : ∃ S ⊆ [m], |S| ≤ d, K_S nonsingular, K_S(x;λ) = r_S, Ax ≤ b }`.

**Active data.** For `x ∈ P`: `I(x) = { i : a_i^T x = b_i }`,
`T(x) = ker A_{I(x)}` (with `T = R^d` if `I(x) = ∅`), and
`ρ(x) = rank A_{I(x)} = d − dim T(x)`. A **basis of the active rows** at `x` is
a set `S ⊆ I(x)` whose rows `{a_i : i ∈ S}` form a basis of
`span{a_i : i ∈ I(x)}`. Then `|S| = ρ(x) ≤ d` and `ker A_S = T(x)`.
Write `F(x) = {y ∈ P : A_{I(x)} y = b_{I(x)}}` (the smallest face of `P`
containing `x`). By Lemma 2.2 below, `F(x)` contains a neighbourhood of `x`
in the affine subspace `{y : A_{I(x)} y = b_{I(x)}}`. Hence
`dim F(x) = d − ρ(x)`, and `x` lies in the relative interior of `F(x)`.

## 2. Complete finite support: statement and proof

### Lemma 2.1 (bordered matrices)
Let `S ⊆ [m]`.

(a) If the rows of `A_S` are linearly dependent, `K_S` is singular.

(b) If the rows of `A_S` are independent and `Z ∈ R^{d×(d−k)}` is a basis
matrix of `ker A_S`, then `K_S` is nonsingular **iff** the reduced Hessian
`Z^T H Z` is nonsingular. (If `k = d`, `Z` is empty and `K_S` is nonsingular.)

*Proof.* (a) If `A_S^T μ = 0` with `μ ≠ 0`, then `K_S(0; μ) = 0`.
(b) Suppose `Z^T H Z` is nonsingular and `K_S(v; μ) = 0`. Then `A_S v = 0`, so
`v = Zw`. Multiplying `Hv + A_S^T μ = 0` by `Z^T` and using `A_S Z = 0` gives
`Z^T H Z w = 0`, so `w = 0` and `v = 0`. Then `A_S^T μ = 0`, and row
independence gives `μ = 0`. Conversely, suppose `Z^T H Z w = 0` with `w ≠ 0`,
and put `v = Zw ≠ 0`. Then `Hv` is orthogonal to `ker A_S`, so
`Hv ∈ range(A_S^T)`. Write `Hv = −A_S^T μ`. Then `K_S(v; μ) = 0` with
`v ≠ 0`. ∎

So the solution of a nonsingular `K_S` is the unique stationary point of `q`
restricted to the affine subspace `E_S = {x : A_S x = b_S}`. That point is a
candidate exactly when it lies in `P`.

### Lemma 2.2 (feasible directions)
Let `x ∈ P` and `v ∈ T(x)`. Then there is an `ε > 0` such that `x + tv ∈ P`
for all `|t| ≤ ε`, and `I(x + tv) ⊇ I(x)` for all such `t`.

*Proof.* For `i ∈ I(x)`, `a_i^T(x+tv) = b_i` because `a_i^T v = 0`. For
`i ∉ I(x)`, `a_i^T x < b_i`, and the strict inequality persists for small
`|t|` because there are finitely many rows. ∎

### Lemma 2.3 (a well-placed minimizer)
Let `P` be nonempty and bounded. Some global minimizer `x_*` of `q` on `P`
satisfies:

1. `∇q(x_*)^T v = 0` for all `v ∈ T(x_*)`;
2. `v^T H v > 0` for all nonzero `v ∈ T(x_*)`, i.e. the reduced Hessian is
   positive definite (vacuous if `T(x_*) = {0}`).

*Proof.* `P` is compact and nonempty, and `q` is continuous, so the set `M` of
global minimizers is nonempty. Choose `x_* ∈ M` with `ρ(x_*)` maximal among
points of `M`. The values lie in `{0, …, d}`, so a maximum exists.

*First and second order.* Let `v ∈ T(x_*)`. By Lemma 2.2,
`φ(t) = q(x_* + tv) = q(x_*) + t ∇q(x_*)^T v + ½ t² v^T H v` has a local
minimum at `t = 0` on `[−ε, ε]`. Hence `∇q(x_*)^T v = 0` and `v^T H v ≥ 0`.

*Positive definiteness.* Suppose `v ∈ T(x_*)`, `v ≠ 0`, and `v^T H v = 0`.
Then `φ(t) = q(x_*)` for **all** real `t`. The set
`Λ = {t ≥ 0 : x_* + tv ∈ P}` is compact because `P` is bounded and `v ≠ 0`.
It is nonempty because it contains 0. Let `t_+ = max Λ` and
`y = x_* + t_+ v`. Then `y ∈ P` and `q(y) = q(x_*)`, so `y ∈ M`. Rows in
`I(x_*)` remain active at `y`. If no row outside `I(x_*)` were active at `y`,
then Lemma 2.2 applied at `y` (note `v ∈ T(y)`) would give `y + εv ∈ P`, which
contradicts maximality of `t_+`. So some `i ∉ I(x_*)` has
`a_i^T y = b_i > a_i^T x_*`, and therefore `a_i^T v > 0`. Every row in
`I(x_*)` vanishes on `v`, so `a_i ∉ span{a_j : j ∈ I(x_*)}`. Hence
`ρ(y) ≥ ρ(x_*) + 1`. This contradicts the maximality of `ρ(x_*)` on `M`. Since
`v^T H v ≥ 0` on `T(x_*)`, the reduced Hessian is PSD; we have shown it has no
nonzero isotropic vector, so it is PD. ∎

(In face language, `x_*` is a minimizer whose minimal face has the smallest
dimension. This version avoids face theory: it uses only active sets and
ranks.)

### Theorem 2.4 (complete finite quadratic support; Report B `thm:polytope`)
Let `P` be bounded.

(i) Every element of `𝒞` lies in `P`. If `P ≠ ∅`, then `𝒞` contains a global
minimizer of `q` on `P`. Hence `min_{x∈𝒞} q(x) = min_{x∈P} q(x)`, and this
value is rational and attained at a rational point.

(ii) `𝒞 = ∅` iff `P = ∅`.

(iii) More precisely, if `x_*` is as in Lemma 2.3, then for **every** basis
`S` of the active rows at `x_*`, `K_S` is nonsingular and its unique solution
has `x`-part `x_*`.

*Proof.* (iii) Let `S` be a basis of the active rows at `x_*`. Then `A_S` has
independent rows, `|S| = ρ(x_*) ≤ d`, and `ker A_S = T(x_*)`. By Lemma 2.3(2)
and Lemma 2.1(b), with `Z` a basis matrix of `T(x_*)`, `Z^T H Z` is PD and
`K_S` is nonsingular. By Lemma 2.3(1), `∇q(x_*) ∈ T(x_*)^⊥ = range(A_S^T)`, so
`Hx_* + c + A_S^T λ = 0` for some `λ`. Also `A_S x_* = b_S` because
`S ⊆ I(x_*)`. Thus `(x_*, λ)` solves the system, and it is the unique
solution.

(i) Every element of `𝒞` is in `P` by the definition of `𝒞`. If `P ≠ ∅`,
(iii) puts `x_* ∈ 𝒞`. So `min_𝒞 q ≤ q(x_*) = min_P q ≤ min_𝒞 q`. Candidates
solve nonsingular rational systems, so they are rational, and so are their
values.

(ii) If `P = ∅`, then `𝒞 ⊆ P` is empty. If `P ≠ ∅`, then `x_* ∈ 𝒞`. ∎

The proof needs no full-dimensionality, constraint qualification, unique
minimizer, PD ambient Hessian, or rank tolerance. Empty `I(x_*)` (interior
minimizer, `S = ∅`, `K_∅ = H`) and vertices (`T = {0}`) are included. Constant
objectives, flat valleys, implicit equalities, zero rows, and degenerate
vertices are all covered (Section 3).

### Proposition 2.5 (optional pruning is also valid)
Let 𝒞⁺ ⊆ 𝒞 keep only the candidates for which some defining `S` has
independent rows, `λ ≥ 0`, and PD `Z^T H Z`. If `P ≠ ∅`, then 𝒞⁺ still
contains a global minimizer.

*Proof.* Take `x_*` from Lemma 2.3. The constraints are linear, so the KKT
conditions hold at the local minimizer `x_*`:
`−∇q(x_*) ∈ cone{a_i : i ∈ I(x_*)}`. This holds because the tangent cone is
`{v : a_i^T v ≤ 0, i ∈ I(x_*)}`, and Farkas' lemma applies. By Carathéodory's
theorem for cones, `−∇q(x_*) ∈ cone{a_i : i ∈ S'}` for some `S' ⊆ I(x_*)`
with independent rows. Extend `S'` by rows of `I(x_*)` to a basis `S` of the
active rows. The representation `−∇q(x_*) = A_S^T λ` is unique, so it is the
Carathéodory representation padded with zeros, and `λ ≥ 0`. By Theorem
2.4(iii) this `S` returns `x_*`, and `Z^T H Z` is PD by Lemma 2.3(2). ∎

The reports correctly say that sign filtering is *unnecessary*. Proposition
2.5 adds that it is *permitted* as pruning, together with a PD test on the
reduced Hessian. Retained non-KKT candidates are harmless because they are
feasible. Example: `q = x` on `[0,1]` retains `x = 1`.

### Remark 2.6 (boundedness is essential; counterexamples)
Report B's implementation enforces boundedness through finite box bounds, and
it must. Without boundedness both conclusions fail:

- `P = {x ∈ R : −x ≤ 0}` (unbounded) and `q = −x`. `S = ∅` gives the
  singular `K = [0]`. `S = {1}` gives `K = [[0,−1],[−1,0]]`, which is
  nonsingular, with solution `x = 0`, which is feasible. The enumeration
  reports minimum `0`, but `inf q = −∞`. **False support value.**
- `P = R` (no rows) and `q = x`. Only `S = ∅`, with singular `K = [0]`.
  `𝒞 = ∅`, but `P ≠ ∅`. **False emptiness certificate.**

Both cases are in `M2_polytope_checks.py`.

## 3. Which subsets are needed (task 2)

### Proposition 3.1
(a) A subset with linearly dependent rows never gives a nonsingular `K_S`
(Lemma 2.1(a)). Such subsets include any subset containing a zero row, a
duplicate pair, a positively scaled copy, or both sides of an equality.

(b) Enumerating only the **linearly independent** subsets, i.e. the subsets
whose size equals their rank, therefore gives exactly the same candidate set
𝒞. Theorem 2.4 holds verbatim for this restricted enumeration.

(c) Any single fixed subset size is insufficient. For example, the
vertex-only enumeration (`|S| = d`, which equals `rank A` for nonempty bounded
`P`) fails for `q = x² − x` on `[0,1]`: it returns `0` instead of `−1/4`. The
needed size is `ρ(x_*) = d − dim F(x_*)`, which depends on the instance and
ranges over all of `0..d`.

(d) Duplicate rows, scaled copies, opposite pairs, zero rows, and redundant
rows cannot break the nonsingularity claim. The claim is made only for a
**basis** of the active rows (Theorem 2.4(iii)), which by definition has
independent rows. Its kernel is `T(x_*)` whatever redundant active rows are
present. Degenerate points are handled too. At the apex of a square pyramid
(4 active facets of rank 3), all four 3-subsets are bases, and each returns
the apex. On an edge with three active rows of rank 2 (one redundant facet),
every independent pair returns the edge minimizer. Both cases are verified.

(e) Nearly parallel but distinct binary64 rows are independent. They can give
nonsingular systems whose solutions lie far away; these are removed by the
exact feasibility test. Their sizes are still bounded by Lemma 4.3.

(f) **The minimal-face choice is what makes the argument work.** At a global
minimizer that is not chosen as in Lemma 2.3, every basis of the active rows
can give a *singular* `K_S`. Example: `q = (x−y)²` on `[0,1]²`. Points
`(t,t)` with `0<t<1` are global minimizers with `I = ∅` and singular `H`. They
are never candidates. The enumeration returns the endpoints `(0,0)` and
`(1,1)` instead (verified). So a proof that starts from an arbitrary
minimizer would be incomplete.

**Work savings.** Skipping subsets that contain two parallel rows is a cheap
a-priori filter. For the box rows alone, the independent subsets are the
`Σ_k C(d,k) 2^k = 3^d` faces of the cube, against
`Σ_{k≤d} C(2d,k) ≥ 2^{2d−1}` subsets counted by `N`. For `d = 4` with no
extra rows: 81 against 163.

## 4. Operation count and explicit encoding lengths (task 1)

### Proposition 4.1 (arithmetic operations; Report B count)
The enumeration uses `O(N (d³ + m d))` rational arithmetic operations and
comparisons, where `N = N(m,d) = Σ_{k=0}^{min(d,m)} C(m,k)`.

*Proof.* Per subset: forming `K_S` takes `O(d²)` operations; elimination on
order `n ≤ 2d` takes `O(n³) = O(d³)`; the feasibility test takes `m` inner
products, `O(md)`; evaluating `q` takes `O(d²)`; one comparison with the
running minimum takes `O(1)`. ∎

Bounds: `N ≤ (m+1)^d`, since `C(m,k) ≤ m^k ≤ C(d,k) m^k`. Also
`N ≤ (e m / d)^d` for `1 ≤ d ≤ m`. For fixed `d` this is `O(m^d)`.

### 4.2 Encoding conventions
For an integer `z`, `⟨z⟩ = 1 + ⌈log₂(|z|+1)⌉`. For a rational `r = p/s` in
lowest terms (`s ≥ 1`), `⟨r⟩ = ⟨p⟩ + ⟨s⟩`. For a list, `⟨·⟩` is the sum of
the sizes of its entries. Then `|p| < 2^{⟨p⟩−1}` and `s < 2^{⟨s⟩−1}`.
Elementary facts, with short proofs:

- `⟨r_1 ⋯ r_k⟩ ≤ Σ⟨r_i⟩`. The numerator is `Π p_i`, and
  `log₂(Π|p_i|+1) ≤ Σ log₂(|p_i|+1)`; the same holds for the denominators.
  Reducing to lowest terms only decreases sizes.
- `⟨r_1 + ⋯ + r_k⟩ ≤ 2Σ⟨r_i⟩`. The numerator
  `Σ_i p_i Π_{j≠i} s_j` has absolute value at most
  `Π_i(|p_i| + s_i) ≤ Π_i (|p_i|+1)(s_i+1)`, and the denominator is
  `Π s_i`.

Let `⟨row_i⟩ = ⟨(a_i, b_i)⟩` and `α₀ := max_i ⟨row_i⟩`. Let `⟨q⟩` be the size
of the monomial coefficient list `(c_0, c, (Q_ij)_{i≤j})`. Let `L` be the
total input size, so `α₀, ⟨q⟩, d, m ≤ L`.

### Lemma 4.2 (integral rescaling)
(a) For each row `i`, let `ρ_i` be the product of the denominators of the
entries of `(a_i, b_i)`. Then `ρ_i a_i` and `ρ_i b_i` are integral, with
entries bounded by `2^{⟨row_i⟩} ≤ 2^{α₀}` in absolute value. Let `σ` be the
product of the denominators of `q`'s monomial coefficients. Then
`σ ≤ 2^{⟨q⟩}`, and `σq` has integer monomial coefficients bounded by
`2^{⟨q⟩}`. Hence `H̃ = σH` and `c̃ = σc` have integer entries bounded by
`2^{⟨q⟩+1}`. (For an entry `p_j/s_j`,
`|p_j Π_{l≠j} s_l| < 2^{Σ_l ⟨p_l/s_l⟩}`.)

(b) Positive row scalings `D = diag(ρ_S)` and the objective scaling `σ > 0`
preserve the nonsingularity of `K_S` and the `x`-part of its solution. With
`K̃_S = [[σH, A_S^T D], [D A_S, 0]]` and `r̃_S = (−σc; D b_S)`:

```
K̃_S = diag(√σ I_d, D/√σ) · K_S · diag(√σ I_d, D/√σ),
```

and `K̃_S (x; μ) = r̃_S  ⇔  K_S (x; Dμ/σ) = r_S`.

*Proof of (b).* Multiply out the blocks: the top-left block is
`√σ H √σ = σH`; the top-right block is `√σ A_S^T D/√σ = A_S^T D`; the bottom
block is symmetric. For the second claim,
`σHx + A_S^T Dμ = −σc ⇔ Hx + c + A_S^T(Dμ/σ) = 0`, and
`DA_S x = Db_S ⇔ A_S x = b_S`. ∎

**Definition.** Let `α` and `η` be nonnegative integers such that
`|ã_ij|, |b̃_i| ≤ 2^α` for the scaled rows and `|H̃_ij|, |c̃_j| ≤ 2^η`. By
Lemma 4.2(a) one may take `α = α₀` and `η = ⟨q⟩ + 1`. For binary64 data,
using the lcm of the (power-of-two) denominators in place of their product
gives much smaller `α`; all bounds below hold for any valid `α, η`.

### Lemma 4.3 (Hadamard bound for bordered systems)
Let `|S| = k`, `n = d + k`, and let `M` be **any** square submatrix of the
integer augmented matrix `[K̃_S | r̃_S]`. Then

```
|det M| ≤ B_k := n^{n/2} · 2^{dη + 2kα} ≤ B := (2d)^d · 2^{d(η + 2α)}.
```

In particular, if `K̃_S` is nonsingular, then `Δ = det K̃_S ∈ Z∖{0}`, and by
Cramer's rule `x_j = N_j/Δ`, where `N_j` is `det K̃_S` with column `j` replaced
by `r̃_S` (`j ≤ d`). Moreover `|Δ|, |N_j| ≤ B_k`.

*Proof.* Let `E = diag(I_d, 2^{−α} I_k)`, and multiply the last `k` rows of
`[K̃_S | r̃_S]` by `2^{−α}` and the last `k` columns of `K̃_S` by `2^{−α}`
(left and right multiplication by `E`; the `r̃` column is not scaled on the
right). The entries of the scaled matrix then satisfy:

- top `d` rows: `H̃` and `−c̃` entries are bounded by `2^η`, and the scaled
  `A_S^T D` entries by `1`;
- bottom `k` rows: the scaled `DA_S` and `Db_S` entries are bounded by `1`,
  and the zero block stays zero.

A square submatrix `M` of order `s ≤ n` picks `t ≤ d` top rows, `u ≤ k`
bottom rows, and `w ≤ k` columns among the last `k`. Its scaled version `M'`
has `det M' = 2^{−α(u+w)} det M`. Each top row of `M'` has Euclidean norm at
most `√s · 2^η`, and each bottom row at most `√s`. Hadamard's inequality
(Grötschel–Lovász–Schrijver 1988, (0.1.28)) gives
`|det M'| ≤ s^{s/2} 2^{tη}`. Hence
`|det M| ≤ s^{s/2} 2^{tη + α(u+w)} ≤ n^{n/2} 2^{dη + 2kα}`. The bound is
increasing in `k ≤ d`, and `n ≤ 2d`. ∎

The bound is attained at `d = 1`, `k = 0`, `H̃ = ±2^η` (ratio 1 in the
script).

### Theorem 4.4 (sizes of candidates and of the support value)
Every candidate `x ∈ 𝒞` has coordinates `x_j = p_j/s_j` in lowest terms with
`|p_j|, s_j ≤ B`. In particular, the minimizer returned by Theorem 2.4 has this
property. The support value `q_* = min_P q` equals `M/R` with integers

```
|M| ≤ (d+1)² · 2^{⟨q⟩} · B²,     1 ≤ R ≤ 2^{⟨q⟩} · B².
```

With `α = α₀` and `η = ⟨q⟩+1`:

```
log₂ B = d·log₂(2d) + d(⟨q⟩+1) + 2d·α₀,
⟨x_j⟩ ≤ 2 log₂ B + 6,
⟨q_*⟩ ≤ 4 log₂ B + 2⟨q⟩ + 2 log₂(d+1) + 6.
```

So candidate and value sizes are `O(d(⟨q⟩ + α₀ + log d)) ⊆ O(L²)`. This holds
for **every** `d`, not only fixed `d`, and the bound does not depend on the
number of rows `m` except through `α₀`.

*Proof.* Lemma 4.3 gives `x_j = N_j/Δ` with `|N_j|, |Δ| ≤ B`. Reducing to
lowest terms only shrinks numerator and denominator. Use `⟨z⟩ ≤ log₂|z| + 3`
for `z ≠ 0`. For the value, let `Q̃ = σQ` and `c̃_0 = σc_0` (integers bounded by
`2^{⟨q⟩}`). Then

`σ q(N/Δ) = (Δ² c̃_0 + Δ Σ_j c̃_j N_j + Σ_{i≤j} Q̃_ij N_i N_j)/Δ²`.

This sum has `1 + d + d(d+1)/2 ≤ (d+1)²` terms, each bounded by
`2^{⟨q⟩} B²`. Put `R = σΔ² ≤ 2^{⟨q⟩} B²`. ∎

### Theorem 4.5 (bit complexity)
The algorithm can be run entirely in integer arithmetic:

1. Scale the rows and the objective as in Lemma 4.2. This costs `O(md + d²)`
   multiplications.
2. For each subset, run fraction-free (Bareiss) elimination on
   `[K̃_S | r̃_S]`, in its integer-preserving Gauss–Jordan form. This takes
   `O(n³)` integer operations, and every intermediate value is a minor of
   `[K̃_S | r̃_S]` (Sylvester's identity; Bareiss 1968).
   By Lemma 4.3 these are bounded by `B`, and the products before each exact
   division are bounded by `2B²`. The output is `Δ` and the `N_j`.
3. Test feasibility as `sign(Δ)(b̃_i Δ − ã_i^T N) ≥ 0`, using integers bounded
   by `(d+1) 2^α B`.
4. Compare values `M/(σΔ²)` by cross-multiplication, using integers bounded
   by `(d+1)² 2^{⟨q⟩} B⁴`.

So all integers have bit length at most
`β := 4 log₂ B + ⟨q⟩ + 2 log₂(d+1) + 2 = O(d(⟨q⟩ + α₀ + log d))`, and the
running time is

```
O( N(m,d) · (d³ + md) · β² )      (schoolbook multiplication).
```

For each fixed `d`, `N ≤ (m+1)^d ≤ (L+1)^d` and `β = O(L)`, so the time is
polynomial in `L`. Moreover, the number of arithmetic operations
`O(m^d (d³ + md))` does not depend on the bit sizes, and every number has
polynomial size. So for fixed `d` the algorithm is **strongly polynomial**.
Equivalently, one can run Gaussian elimination over `Q` in coprime
representation, which runs in polynomial time (Edmonds 1967; GLS 1988,
Theorem (1.4.8)). Report B's Python `Fraction` implementation is of that
kind. When `d` is part of the input, only `N` is exponential; this is
unavoidable (Proposition 5.2).

This agrees with the remark in Del Pia and Khajavirad (2026, p. 1) that box
QP with a fixed number of variables is strongly polynomial "using a simple
face enumeration argument", citing Vavasis (1990) and Del Pia–Dey–Molinaro
(2017). The tractability claim is classical. The new content is the explicit
nonsingular-system formulation, the constants, and the certificate design.

## 5. Rationality, NP membership, hardness (task 3)

### Corollary 5.1 (rational minimum of polynomial size)
If `P` is nonempty and bounded, then `min_P q` is a rational number attained
at a rational point. Both have the explicit sizes of Theorem 4.4, which are
polynomial in the input size for unrestricted `d`. Hence the decision problem
"is there `x ∈ P` with `q(x) ≤ t`?" (bounded `P`) is in NP. The witness is
the minimizer `x_*`, or the pair `(S, x_*)`.

*Relation to Vavasis (1990).* Vavasis proved that the decision version of
quadratic programming is in NP. As restated by Del Pia, Dey, and Molinaro
(2017, Theorem 3, p. 3): if a rational QP has a global optimum, then some
global optimum solves a rational linear system of small complexity. Vavasis
(1992, p. 1) and Bienstock, Del Pia, and Hildebrand (2023, p. 2) also cite
it. Corollary 5.1 is the **bounded** special case, with a self-contained proof
and explicit constants. Vavasis' theorem also covers unbounded feasible
regions with an attained optimum. *Source caveat:* the local knowledge base
has only metadata for Vavasis (1990). The statement above relies on these
secondary sources, and its proof was not audited. The paper should present
Corollary 5.1 with its own proof and cite Vavasis for the general case.

*Remark (pointed extension).* The proof of Lemma 2.3 uses boundedness only to
make `Λ` compact. If `P` is pointed (contains no line) and `q` attains its
minimum on `P`, then either `max Λ` or `max{t ≥ 0 : x_* − tv ∈ P}` is finite.
Otherwise `P` would contain the line `x_* + Rv`. So Theorem 2.4(i), (iii) and
Theorem 4.4 hold for pointed `P` with an attained minimum. Remark 2.6 shows
that attainment cannot be dropped. Deciding attainment (unboundedness) for
indefinite QP is itself NP-hard (Murty–Kabadi 1987, as cited by Vavasis 1992,
p. 4). The paper only needs the bounded case.

*Contrast.* Rationality is specific to a quadratic objective with linear
constraints. `min (x³ − 6x)` on `[0,3]` is attained at `√2` with value
`−4√2`, and `min x` subject to `x² ≥ 2`, `x ∈ [0,2]` equals `√2`. For degree
at least 3, only certified enclosures are possible in general, which is the
C-BERN route.

### Proposition 5.2 (MaxCut hardness; Report B `prop:hardness`)
Given a graph `G = (V,E)` with weights `w ∈ Z_{≥0}^E`, put
`q_G(x) = −Σ_{ij∈E} w_ij (x_i + x_j − 2x_i x_j)` on `[0,1]^V`. Then
`min_{[0,1]^V} q_G = −MaxCut(G,w)`. Hence computing the exact support of the
quadratic graph hull `conv{(x, (x_i x_j)_{ij∈E}) : x ∈ [0,1]^V}` in a given
rational direction is NP-hard when the dimension is part of the input. With
unit weights, all coefficients have absolute value at most `max(2, deg)`, so
the problem is **strongly** NP-hard.

*Proof.* `q_G` has no `x_i²` terms, so it is affine in each coordinate when
the others are fixed. Start from a global minimizer, which exists by
compactness. Replace `x_1` by an endpoint of `[0,1]` that minimizes the
affine function of `x_1`; the value does not increase. Repeat for each
coordinate. The result is a binary point with value at most the minimum, so
it is a global minimizer. At binary `x`, `x_i + x_j − 2x_i x_j = 1` iff
`x_i ≠ x_j`, so `q_G(x)` equals minus the weight of the cut
`{i : x_i = 1}`. So `min q_G = −MaxCut`. The direction `(c, a)` with
`c_i = −Σ_{j: ij∈E} w_ij` and `a_ij = 2w_ij` has encoding size polynomial in
`(G, w)`. Weighted MAX CUT is NP-complete (Karp 1972). Unweighted MAX CUT is
NP-complete (Garey, Johnson, and Stockmeyer 1976; not in the local knowledge
base, so check before citing), which gives strong NP-hardness. ∎

### Corollary 5.3 (decision version)
"Given rational `q`, a rational bounded `P` (or a box), and `t ∈ Q`, is
`min_P q ≤ t`?" is NP-complete: membership by Corollary 5.1, hardness by
Proposition 5.2.

### Corollary 5.4 (validity of a given cut is coNP-complete)
VALID: "given `q`, bounded `P`, and `t`, does `q(x) ≥ t` hold for all
`x ∈ P`?" is coNP-complete. So unless NP = coNP, there is no
polynomial-size, polynomial-time-checkable certificate of the validity of an
exact quadratic support cut in unrestricted dimension.

*Proof.* The complement, "∃x ∈ P with q(x) < t", is in NP. If `min q < t`,
the minimizer from Corollary 5.1 is a polynomial-size witness, and checking
`x ∈ P` and `q(x) < t` is polynomial. For hardness, with integer weights,
`min q_G` is an integer by Proposition 5.2. So `MaxCut ≥ W` iff
`min q_G ≤ −W` iff `NOT VALID(q_G, [0,1]^V, −W + ½)`. ∎

*Consequence for the paper's certificate design (N4).* The C-POLY
certificate is a complete enumeration whose replay repeats all `N` subsets.
Its size and cost are exponential in `d`. Corollary 5.4 shows that this is
not a weakness of the design: in unrestricted dimension, short certificates
would imply NP = coNP. Structured classes such as C-STAR, or fixed `d`, are
the routes to small certificates.

### 5.4 Citation recommendation for hardness
- **Cite Karp (1972)** for the proposition as proved. The reduction uses
  weighted MAX CUT. Report B's literature notes record that pp. 94, 97, and
  100 of the reprint were inspected. Add Garey–Johnson–Stockmeyer (1976) if
  the strong NP-hardness remark is kept.
- **Pardalos and Vavasis (1991)**, "Quadratic programming with one negative
  eigenvalue is NP-hard" (J. Global Optim. 1:15–22), is **not** the source of
  the box/MaxCut statement. It shows hardness under a much weaker curvature
  restriction (one negative eigenvalue) over general polyhedra. It is
  appropriate context: restricting curvature does not restore tractability.
  It should not replace Karp.
- Further context: Sahni (1974) is credited with the first NP-hardness proof
  for QP (Vavasis 1992, p. 1). Del Pia and Khajavirad (2026, p. 1) state
  box-QP NP-hardness via max cut, and the fixed-dimension face-enumeration
  tractability. Their strong NP-hardness at treewidth two (p. 3, p. 20) is
  relevant to any "sparse block" tractability hope.

## 6. Vectors of quadratic features (task 4)

### Corollary 6.1 (exact support of a quadratic feature graph)
**Hypotheses.** `P ⊂ R^d` is a nonempty bounded rational polytope.
`f = (f_1, …, f_p)` with `f_j(x) = ½ x^T H_j x + g_j^T x + f_{j0}` and
rational data. Let `G_f = {(x, f(x)) : x ∈ P}` and `C_f = conv G_f`. For
`(α, a) ∈ Q^d × Q^p`, define

```
q_{α,a}(x) = α^T x + a^T f(x) = ½ x^T(Σ_j a_j H_j)x + (α + Σ_j a_j g_j)^T x + Σ_j a_j f_{j0},
h_f(α,a)   = min{ α^T x + a^T y : (x,y) ∈ C_f }.
```

**Conclusions.**

1. `C_f` is compact, and `h_f(α,a) = min_{x∈P} q_{α,a}(x)`.
2. The enumeration of Theorem 2.4 applied to `q_{α,a}` returns
   `h_f(α,a) ∈ Q` and a rational `x_*`. The inequality
   `α^T x + a^T y ≥ h_f(α,a)` is valid for `C_f` and holds with equality at
   the graph point `(x_*, f(x_*))`, so no larger right-hand side is valid. This
   is the exact support cut with normal `(α, a)`.
3. `C_f = ∩_{(α,a) ∈ Q^{d+p}} {(x,y) : α^T x + a^T y ≥ h_f(α,a)}`. Rational
   (in particular binary64) normals suffice.
4. Forming `q_{α,a}` costs `O(p d²)` operations, and the support then costs
   `O(N(d³+md))`. Let `⟨f_j⟩` be the size of `f_j`'s monomial coefficient
   list, and `C = (d+1)(d+2)/2` the number of monomials. Applying the
   Section 4.2 rules coefficientwise gives
   `⟨q_{α,a}⟩ ≤ 2C Σ_j⟨a_j⟩ + 2Σ_j⟨f_j⟩ + 2⟨α⟩`. Hence `h_f(α,a)` has
   size polynomial in `(⟨α⟩, ⟨a⟩, ⟨f⟩, ⟨P⟩)` for every `d`. For fixed `d` it is computable in
   strongly polynomial time. With `d` unrestricted it is NP-hard
   (Proposition 5.2, where `p = |E|` and `f` is the edge products).
5. *(Universal moment hull.)* Let `v(x) = (x_i x_j)_{i≤j}`. Every quadratic
   `f` has the form `f(x) = Wv(x) + Gx + f_0`. Hence
   `C_f = { (x, Ww + Gx + f_0) : (x, w) ∈ C_v }`, and
   `h_f(α, a) = h_v(α + G^T a, W^T a) + a^T f_0`. All quadratic feature
   vectors over `P` are therefore affine images of the single moment hull
   `C_v = conv{(x, (x_i x_j)_{i≤j}) : x ∈ P}`.

*Proof.* (1) `G_f` is the continuous image of the compact set `P`. `C_f` is
the image of the compact set `G_f^{d+p+1} × Δ_{d+p}` under
`(z_0..z_{d+p}, θ) ↦ Σ θ_l z_l` (Carathéodory), so it is compact. A linear
function attains the same minimum over a set and over its convex hull.
(2) Apply (1) and Theorem 2.4. Equality holds at `(x_*, f(x_*)) ∈ G_f ⊆ C_f`.
(3) "⊆" is clear. For "⊇", let `z ∉ C_f`. `C_f` is closed and convex, so
there is `w` with `w^T z < h_f(w)`, where `h_f(w)` denotes the support value
in direction `w = (α,a)`. Let `R = max_{u∈C_f} ‖u‖`. Then `h_f` is
`R`-Lipschitz, since `|min_u w^T u − min_u w'^T u| ≤ R‖w − w'‖`. Pick a
rational `w'` with `‖w − w'‖ < (h_f(w) − w^T z)/(R + ‖z‖ + 1)`. Then
`w'^T z ≤ w^T z + ‖z‖‖w−w'‖ < h_f(w) − R‖w − w'‖ ≤ h_f(w')`, so the rational
cut with normal `w'` separates `z`. (4) Proposition 4.1, Theorem 4.4,
Theorem 4.5, and Proposition 5.2. (5) Affine maps commute with convex hulls.
Then substitute `y = Ww + Gx + f_0` into `α^T x + a^T y`. ∎

*Remarks.*

- `C_f` is generally **not polyhedral**. For `d = p = 1`, `f = x²` on `[0,1]`,
  `C_f = {(x,y) : x² ≤ y ≤ x}`. So (3) needs infinitely many normals, and
  finding a violated normal for a given point is a separation problem (C-SEP),
  not a support problem.
- The exact `h_f` is rational but not binary64 in general. The exported row
  must round its right-hand side downward, which preserves validity because
  the cut has the form `≥ h`. That is part of the C-SUP contract.
- For a vector of features with **shared** domain `P`, the support is that of
  the joint hull `C_f`, not the intersection of the separate hulls of the
  `f_j`. This joint support is the point of C-SUP and is the object studied in
  C-OVER.

## 7. Report A: the two-dimensional theorem and the simplex example

### 7.1 Theorem `thm:polygon` (Report A)
*Statement (paraphrase).* Let `P ⊂ R²` be a nonempty bounded rational
polyhedron and `q` a rational quadratic. The minimum is attained at a rational
point that is (1) a vertex; (2) a stationary point in the relative interior
of an edge, or of `P` itself when `P` is a segment, along which `q` has
strictly positive curvature; or (3) the stationary point of `q` when the
Hessian is PD and `dim P = 2`.

*Verdict: correct.* It follows from Lemma 2.3. Take `x_*` from Lemma 2.3 and
let `F = {y ∈ P : A_{I(x_*)} y = b_{I(x_*)}}`, so `dim F = 2 − ρ(x_*)` and
`x_*` is in the relative interior of `F` (Lemma 2.2).

- `ρ = 2`: `x_*` is a feasible point with two independent active rows, i.e. a
  vertex. This is case (1).
- `ρ = 1`: `F` is a segment, either an edge of a two-dimensional `P` or `P`
  itself. `x_*` lies in its relative interior, and Lemma 2.3 gives zero
  derivative and strictly positive curvature along `F`. This is case (2).
- `ρ = 0`: `x_*` is interior to a two-dimensional `P`, with `∇q = 0` and PD
  Hessian. This is case (3).

Report A's own proof, which restricts to the boundary and uses a null-direction
line in the interior, is also correct. Its candidate list is a pruned version
of 𝒞, consistent with Proposition 2.5. The implementation enumerates
`C(m,2)` line pairs, each checked against `m` rows, so it is `O(m³)`, and the
`O(m)` hull edges add lower-order work. A random comparison of Report A's rule
with the bordered enumeration agreed on 80 of 80 instances (my
implementation). Report A's code agreed with my enumeration on all tested 2-D
instances (Section 9).

### 7.2 The simplex example
Let `Δ = {x, y ≥ 0, x + y ≤ 1}`, with lifted coordinates
`(x, y, X, Z, W) ↔ (x, y, x², xy, y²)`.

(a) *Validity on `C(Δ) = conv{(x,y,x²,xy,y²) : (x,y) ∈ Δ}`.*
`X + 2Z + W ≤ x + y` holds because `s = x+y ∈ [0,1]` gives `s² ≤ s`.
`Z ≤ 1/4` holds because `4xy ≤ (x+y)² ≤ 1`. Both are linear in the lifted
coordinates, so they hold on the convex hull. Both are tight: the first at
`(0,0)` and on the edge `x+y=1`, the second at `(½,½)`. The exact enumeration
confirms minimum value 0 in both cases.

(b) *The box-hull point.* `z̄ = ½(0,0,0,0,0) + ½(1,1,1,1,1) = (½,½,½,½,½)`
lies in `C([0,1]²)` and satisfies `x + y = 1 ≤ 1`. It violates (a):
`X + 2Z + W = 2 > 1 = x + y` and `Z = ½ > ¼`. Since
`C(Δ) ⊆ C([0,1]²) ∩ {x+y ≤ 1}`, the inclusion is **strict**. Report A's claim
is correct.

(c) *Quantification (new).* Over `C([0,1]²) ∩ {x + y ≤ 1}`, the maximum of
`X + 2Z + W − x − y` is exactly `1`, and the maximum of `Z` is exactly `½`.
Both are attained at `z̄`. Proof: points of `C([0,1]²)` are moment vectors of
probability measures `μ` on `[0,1]²` (Carathéodory). With `s = x + y ∈ [0,2]`,
`s² − s ≤ s`, so `E_μ[s² − s] ≤ E_μ[s] ≤ 1`. Also `xy ≤ min(x,y) ≤ (x+y)/2`,
so `E_μ[xy] ≤ ½`. A grid LP confirms the value 1.

(d) **Caveat for the paper.** The example compares against "box hull ∩ row",
not against standard relaxations. With
`Y = [[1,x,y],[x,X,Z],[y,Z,W]]` and pairwise RLT of the facet functions
`(x, y, 1−x−y)`:

- `X + 2Z + W ≤ x + y` is the **sum of two RLT inequalities**,
  `x − X − Z ≥ 0` (from `x(1−x−y) ≥ 0`) and `y − Z − W ≥ 0`.
- `Z ≤ ¼` follows from the PSD minor `X + W − 2Z ≥ 0` together with
  `X + 2Z + W ≤ x + y ≤ 1`, which give `4Z ≤ 1`.
- The single RLT row `x − X − Z ≥ 0` already cuts `z̄` (value `−½`).
- More strongly, for a triangle, `C(Δ)` **equals** PSD + pairwise RLT. This is
  Anstreicher and Burer (2010, abstract p. 1; Theorem 3, p. 4; corollary for
  triangles and tetrahedra, p. 5): a DNN representation for the standard
  simplex with matrix order at most 4, transferred to triangles and
  tetrahedra by an affine bijection. Under that map, DNN of the
  barycentric moment matrix is exactly PSD of `Y` plus pairwise RLT. Over 25
  random directions, the exact support and the PSD+RLT SDP value agreed to
  `1.6·10⁻⁷`, the solver tolerance.

So the example correctly motivates convexifying the row domain jointly. It
must not be presented as a gain over RLT/SDP. The exact oracle's distinct
contributions are exact rational support values with replayable
certificates, for arbitrary bounded polytopes in the admitted small
dimensions. Closed-form DNN/RLT descriptions of the hull are known only for
special domains, for example triangles, tetrahedra, and the 2-D box. For the
3-cube, Anstreicher and Burer combine the simplex result with a
triangulation (2010, p. 1).

## 8. Recommended statements for the paper

1. **Theorem (C-POLY).** "Let `P = {x ∈ R^d : Ax ≤ b}` be **bounded**, with
   rational data, and let `q` be a rational quadratic. Let 𝒞 be the set of
   feasible `x`-parts of the unique solutions of the nonsingular bordered
   systems `K_S`, over all row subsets with `|S| ≤ d`. Linearly independent
   subsets suffice. Then 𝒞 ⊆ P, 𝒞 = ∅ iff P = ∅, and otherwise
   `min_𝒞 q = min_P q`. For a minimizer chosen with maximal active rank,
   every basis of its active rows returns it." Add one sentence noting that
   boundedness is necessary for both conclusions (Remark 2.6).
2. **Complexity.** Keep `O(N(d³+md))` arithmetic operations. Replace "rational
   determinant bounds control the encoding lengths" with Theorem 4.4's
   explicit bound `|num|, den ≤ (2d)^d 2^{d(η+2α)}`, and add: "strongly
   polynomial for fixed `d`; number sizes are polynomial for all `d`". Credit
   the fixed-dimension tractability to Murty (1997, §2.9), Vavasis (1990), and
   the remark in Del Pia–Khajavirad (2026, p. 1).
3. **Hardness.** Keep the Karp (1972) citation. Optionally add "strongly
   NP-hard" (Garey–Johnson–Stockmeyer 1976, after checking) and Corollary
   5.4 (coNP-completeness of cut validity), which justifies replay by full
   enumeration. Cite Pardalos–Vavasis (1991) only as related hardness.
4. **Polygon example.** Add: "Pairwise RLT and PSD already describe the exact

5. **Vector features.** State Corollary 6.1(1)–(3) as the C-POLY consequence
