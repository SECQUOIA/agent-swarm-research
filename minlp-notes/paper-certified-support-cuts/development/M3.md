## 1. Setting and hypotheses

Variables: a center `y` and leaves `x_1,...,x_k` (`k >= 0`). All data are rational. A finite binary64 input denotes its exact rational value.

Objective:

```
q(y,x) = a0 + a1*y + a2*y^2 + sum_i q_i(y,x_i),    q_i(y,x) = d_i*x^2 + (e_i*y + f_i)*x.
```

Every coefficient can have any sign. Up to a constant this is the most general quadratic with no leaf–leaf products: center–leaf products, all squares, and all linear terms. For a direction in the lifted coordinates `(y, y^2, x_i, x_i^2, y*x_i)`, the scalar support objective has exactly this form.

Domain `D`:

- (H1) Finite center bounds `ly <= y <= uy`.
- (H2) Center-only rows `p*y <= c`. There are `r0` of them.
- (H3) Finite leaf bounds `l_i <= x_i <= u_i`.
- (H4) Leaf rows `p*y + b*x_i <= c` with `b != 0` and `p` arbitrary (`p = 0` allowed). Leaf `i` has `m_i` such rows; write `m_L = sum_i m_i` and `m = r0 + m_L`.
- An equality is given as two inequalities. Rows containing two different leaves are excluded, and so are leaf–leaf products.

Notation:

- `I0 = {y in [ly,uy] : all center-only rows hold}`, a closed interval or empty.
- `P_i = {(y,x_i) : y in I0, l_i <= x_i <= u_i, rows of leaf i}`.
- `D = {(y,x) : (y,x_i) in P_i for all i}`, with `D = I0` if `k = 0`.

Lines of leaf `i`:

- Lower set `Low_i = {(l_i, 0)} ∪ {(c/b, -p/b) : row with b < 0}`.
- Upper set `Up_i = {(u_i, 0)} ∪ {(c/b, -p/b) : row with b > 0}`.
- A pair `(alpha, beta)` denotes the affine function `alpha + beta*y`.
- `L_i(y) = max over Low_i`, `U_i(y) = min over Up_i`.
- `s_i = |Low_i| + |Up_i| = m_i + 2`.
- `s_i'` is the number of distinct lines that attain the max (or min) on a nondegenerate subinterval of the final center interval `I`. Thus `2 <= s_i' <= s_i`.

Remark on (H1) and (H3). Report B says "finite variable bounds are rational", which can be read as "the finite bounds are rational". The proof needs every envelope to be nonempty and `I` to be compact. The minimal hypothesis is that each `P_i` is bounded and `I0` is bounded. Then each fiber is bounded on `I`, so each envelope contains at least one line. Finite box bounds imply this, and the implementation requires them. Without boundedness the statement fails: with `d_i < 0` and `x_i` unbounded, the infimum is `-inf`.

## 2. Structure lemmas

**Lemma 1 (fibers).** For `y in I0`, `{x : (y,x) in P_i} = [L_i(y), U_i(y)]`. This interval is empty if `L_i(y) > U_i(y)`.

*Proof.* If `b > 0`, the row `p*y + b*x <= c` is equivalent to `x <= (c - p*y)/b`. If `b < 0`, it is equivalent to `x >= (c - p*y)/b`. The leaf bounds are the lines `(l_i,0)` and `(u_i,0)`. ∎

**Lemma 2 (projection and conditional independence).** Let `J_i = {y in I0 : L_i(y) <= U_i(y)}`, which is the projection of `P_i` onto `y`. Then:

1. Each `J_i` is a closed interval (possibly empty or a single point) with rational endpoints.
2. `I := I0 ∩ J_1 ∩ ... ∩ J_k` is exactly the projection of `D` onto `y`.
3. `D = {(y,x) : y in I, L_i(y) <= x_i <= U_i(y) for all i}`.

In particular, `D` is empty if and only if `I` is empty.

*Proof.*

- `L_i - U_i = max over pairs (l, u) in Low_i × Up_i of (l - u)` is a maximum of affine functions, hence convex. Its sublevel set `{<= 0}`, intersected with the closed interval `I0`, is therefore a closed interval.
- Each finite endpoint is an endpoint of `I0` (`ly`, `uy`, or some `c/p`) or a root of `l - u` for two lines. Both kinds are rational.
- Each defining condition of `D` involves only `y` and a single `x_i`. So for `y in I`, the fibers can be chosen independently, which gives item 3.
- Item 2 follows from item 3 together with Lemma 1. ∎

**Lemma 3 (envelopes).** On `I`:

- (a) `L_i` is convex piecewise linear, and its breakpoints in the interior of `I` number at most (number of lower lines active on `I`) − 1. The same holds for the concave function `U_i` with the upper lines.
- (b) `L_i <= U_i`. If `L_i(p) = U_i(p)` at an interior point `p` of `I`, then `L_i ≡ U_i` on `I`, and this common function is affine.

*Proof.*

(a) For a line `l` in `Low_i`, the set where `l` attains the max is `{y : l(y) >= l'(y) for all l'}`. This is an intersection of half-lines, hence an interval. Two distinct lines cannot both attain the max on a nondegenerate interval, because they would then coincide. So the nondegenerate active intervals have disjoint interiors and cover `I`, which bounds the number of breakpoints.

(b) `h := L_i - U_i` is convex, and `h <= 0` on `I` by Lemma 2. Suppose `h(p) = 0` at an interior point `p`. For any `a < p < b` in `I`, convexity gives `0 = h(p) <= lambda*h(a) + (1-lambda)*h(b) <= 0`, so `h(a) = h(b) = 0`. Hence `h ≡ 0`. Then `L_i = U_i` is both convex and concave, hence affine. ∎

**Lemma 4 (scalar leaf problem).** Let `lambda <= rho` and `phi(x) = d*x^2 + beta*x`.

- (i) If `d > 0`, the unique minimizer of `phi` on `[lambda, rho]` is `med(lambda, v, rho) = max{lambda, min{v, rho}}`, where `v = -beta/(2d)`.
- (ii) If `d <= 0`, some minimizer lies in `{lambda, rho}`, and `phi(rho) - phi(lambda) = (rho - lambda)(d*(rho + lambda) + beta)`. Hence `lambda` is a minimizer if and only if this product is `>= 0`, and `rho` is a minimizer if and only if it is `<= 0`.

*Proof.*

(i) `phi` is strictly convex with unconstrained minimizer `v`. The derivative `phi'(x) = 2d(x - v)` has the sign of `x - v`. So `phi` decreases up to `v` and increases afterwards, and the constrained minimizer is the projection of `v` onto the interval.

(ii) `phi` is concave if `d < 0` and affine if `d = 0`, so its minimum over a segment is attained at an endpoint. Also `d*rho^2 - d*lambda^2 + beta*(rho - lambda) = (rho - lambda)(d*(rho + lambda) + beta)`. ∎

Applied with `lambda = L_i(y)`, `rho = U_i(y)`, `beta = e_i*y + f_i` and `v_i(y) = -(e_i*y + f_i)/(2d_i)`, this gives the clipping rule and the endpoint factorization of `star.tex`.

## 3. Exact star support theorem (full proof)

Let `I = [lo, hi]`. The *conditional value* is `m_i(y) = min{q_i(y,x) : L_i(y) <= x <= U_i(y)}`. An *affine rule* is a line `r = (alpha, beta)`, meaning `x_i = alpha + beta*y`.

**Construction of leaf candidates.** Assume `lo < hi`.

- Let `E_i` be the set of breakpoints of `L_i` and `U_i` that lie in `(lo, hi)`. These points cut `I` into closed *envelope pieces*. On each piece, `L_i = l` and `U_i = u` for fixed lines `l` and `u`. By continuity this holds on the closed piece, not only on its interior.
- If `d_i > 0`, let `R_i` be the set of roots, strictly inside an envelope piece, of the affine functions `v_i - l` and `v_i - u`. Affine functions that vanish identically contribute no roots.
- If `d_i <= 0`, let `R_i` be the set of roots, strictly inside an envelope piece, of `g = d_i*(l + u) + e_i*y + f_i` (unless `g ≡ 0` there).
- On each subpiece `[a, b]` of the refinement by `E_i ∪ R_i`, choose the rule at an interior point `y0`:
  - If `d_i > 0`: choose `l` if `v_i(y0) <= l(y0)`; else `u` if `v_i(y0) >= u(y0)`; else `v_i`.
  - If `d_i <= 0`: choose `l` if `(u - l)(y0) * g(y0) >= 0`, else `u`.

**Lemma 5 (validity on closed pieces).** On every closed subpiece `[a, b]`, the chosen rule `r` satisfies `L_i(y) <= r(y) <= U_i(y)` and `q_i(y, r(y)) = m_i(y)` for every `y` in `[a, b]`, including the endpoints `a` and `b`.

*Proof.* Case `d_i > 0`.

- No root of `v_i - l` or `v_i - u` lies in `(a, b)` unless that function vanishes identically. So each of these functions is identically zero on `(a, b)` or has a constant strict sign there.
- Hence `med(l, v_i, u)` coincides on `(a, b)` with one fixed member of `{l, v_i, u}`, namely the chosen rule. When `v_i ≡ l` or `v_i ≡ u`, the choice is immaterial.
- Both `y -> med(L_i(y), v_i(y), U_i(y))` and `r` are continuous, so they agree on `[a, b]`.
- By Lemma 4(i), this median is the minimizer at every `y` in `[a, b]`, because `[a, b]` lies in `I`, where `L_i <= U_i`.

Case `d_i <= 0`.

- By Lemma 3(b), either `u ≡ l` on `I`, in which case both rules give the same point, or `u - l > 0` on `(a, b)`.
- In the second case, `g` has constant strict sign on `(a, b)` or vanishes identically. If `g > 0` on `(a, b)`, the rule `l` was chosen. By continuity `g(y) >= 0` on `[a, b]`, and `u - l >= 0`, so Lemma 4(ii) shows `l(y)` is a minimizer at each `y` in `[a, b]`. The case `g < 0` with rule `u` is symmetric. If `g ≡ 0`, both endpoints are minimizers. ∎

So `m_i` agrees on `[a, b]` with the quadratic

```
q_i(y, alpha + beta*y) = (d*alpha^2 + f*alpha) + (2*d*alpha*beta + e*alpha + f*beta)*y + (d*beta^2 + e*beta)*y^2.
```

**Theorem 1 (exact rational star support; corrected statement).** Assume (H1)–(H4) and `D ≠ ∅`. Let `T = {lo, hi} ∪ ⋃_i (E_i ∪ R_i)`, sorted as `t_0 < ... < t_N`. On each closed piece `[t_{j-1}, t_j]`, every leaf has a single affine rule `r_i^j` that is feasible and conditionally optimal on the whole closed piece. Moreover,

```
Phi(y) := min{q(y,x) : (y,x) in D} = a0 + a1*y + a2*y^2 + sum_i q_i(y, r_i^j(y)) =: Phi_j(y)   on [t_{j-1}, t_j].
```

Write `Phi_j(y) = c0 + c1*y + c2*y^2`. The minimum of `q` over `D` equals `min_j min over C_j of Phi_j`, where `C_j = {t_{j-1}, t_j}`, plus `-c1/(2*c2)` when `c2 > 0` and this point lies in `(t_{j-1}, t_j)`. If the minimum is attained at `y*` on piece `j`, a minimizer is `(y*, r_i^j(y*))_i`. All breakpoints, rules, coefficients, the minimizer and the minimum are rational. If `lo = hi`, then `Phi(lo)` is obtained directly from Lemma 4 at `y = lo`.

*Proof.*

- By Lemma 2, `min over D of q = min over y in I of Phi(y)`, and `Phi(y) = a0 + a1*y + a2*y^2 + sum_i m_i(y)`, because the minimization over `x` separates.
- `T` refines every leaf partition. So Lemma 5 applies on each piece, and `Phi = Phi_j` there.
- The minimum of a quadratic over a closed interval is attained at an endpoint, or at the stationary point when `c2 > 0` and that point lies inside the interval. The listed candidates are therefore exhaustive.
- `D` is compact and nonempty, so the minimum is attained.
- Every number is obtained from rational data by field operations, so all are rational. ∎

This is the proof in `star.tex`, with Lemma 5 written out. The singleton case uses Lemma 4 directly.

## 4. Sharp breakpoint counts

**Theorem 3 (per-leaf counts).** Let `B_i = |E_i ∪ R_i|`. Then:

- `|E_i| <= s_i' - 2`.
- If `d_i > 0`, then `|R_i| <= 4`, so `B_i <= s_i' + 2`. The number of points where the minimizing rule actually changes is at most `s_i'`.
- If `d_i <= 0`, then `|R_i| <= s_i' - 1`, so `B_i <= 2s_i' - 3`.
- The bound `2s_i' - 3` is attained for every `N >= 2` (zigzag family below).
- In total, `|T| - 2 <= sum_i 2s_i = 2m_L + 4k`, and this total can be of order `m + k`.

*Proof.*

`|E_i|`: this follows from Lemma 3(a).

`d_i > 0`:

- `v_i - L_i` is concave (affine minus convex). Its zero set in `I` is either a closed interval or at most two points. To see this, suppose a concave function vanishes at `p < q < r`. Being concave, it is `>= 0` on `[p, r]`. If it were positive somewhere in `(p, q)`, concavity on the interval from that point to `r` would force a positive value at `q`. So it vanishes on `[p, r]`.
- A recorded root lies strictly inside an envelope piece where `v_i - l` is affine and not identically zero. So it is an isolated zero of `v_i - L_i`, and there are at most 2 of these.
- If the zero set is a nondegenerate interval `[p, q]`, the active lower line on it is `v_i` itself. Then `p` and `q` are envelope breakpoints or endpoints of `I`, and no root is recorded.
- The same argument applies to the convex function `v_i - U_i`, giving at most 2 more roots.
- Rule changes: let `R_L = {v_i < L_i}`, `R_M = {L_i <= v_i <= U_i}` and `R_U = {v_i > U_i}`. `R_M` is an interval, being the intersection of a superlevel set of a concave function with a sublevel set of a convex function. Its complement in `I` has at most two components. Each component lies entirely in `R_L` or entirely in `R_U`, because passing between them continuously would cross `R_M`. So the minimizer is `L_i`, then `v_i`, then `U_i` (or a sub-sequence of these). It changes only at the at most 2 regime boundaries, at breakpoints of `L_i` inside the `R_L` part, and at breakpoints of `U_i` inside the `R_U` part. In total this is at most `(s_i' - 2) + 2 = s_i'`.

`d_i <= 0`: there are at most `s_i' - 1` envelope pieces, and each contains at most one root of the affine function `g`.

Totals: `s' + 2 <= 2s'` and `2s' - 3 <= 2s'` for `s' >= 2`, and `s_i' <= s_i = m_i + 2`.

**Zigzag family (attainment of `2s'-3`).** Fix `N >= 2` and let `A = N^2 + 2`, so that `A > (N^2 + 3N)/2`. Center `y` in `[0, N]`. One leaf with `x` in `[-10A, 10A]`, `d = -1`, `e = 0`, `f = -1/2`.

- `L(0) = -A`. `L` has slope `2j` on the `j`-th piece, with breakpoints at the odd integers.
- `U(0) = A`. `U` has slope `-(2j+1)` on the `j`-th piece, with breakpoints at the even integers.
- Feasibility: the slope of `L` at `y` is at most `y + 1`, and the slope of `U` is at least `-(y + 2)`. Hence `U - L >= 2A - y^2 - 3y > 0` on `[0, N]`. The box lines are inactive.
- `L + U` starts at 0 and has slopes `-1, +1, -1, ...` on consecutive unit intervals. So it takes the value 0 at even integers and −1 at odd integers.
- `g = -(L + U) - 1/2` is `-1/2` at even integers and `+1/2` at odd integers. So it has a root at every half-integer.
- The minimizer is `U` near even integers and `L` near odd integers. At each integer, the bound chosen there changes its active line.
- Hence the rule changes at the `N` half-integers and the `N - 1` integers: `2N - 1 = 2s' - 3` changes, where `s' = N + 1` active lines.

`M3_bounds_and_examples.py` confirms this for `N = 6, 11, 20`. The optimal values (`-1463`, `-30381/2`, `-161805`) agree with the inherited oracle.

A box leaf with `d = 0` (the hinge `min{0, e*y + f}`) gives one forced change. So `k` box leaves and one zigzag leaf with `m` rows force `Theta(m + k)` pieces. ∎

**About the hint.**

- "`v_i` crosses `L_i` and `U_i` at most twice each": correct, as isolated crossings.
- "At most one root of the endpoint factor per affine piece": correct. But the total over a leaf can be `s_i' - 1`, not `O(1)`, as the zigzag shows.
- "`O(m_i)` breakpoints per leaf" should read `O(m_i + 1)`. Box-only leaves (`m_i = 0`) still contribute up to 2.

## 5. The algorithm and the operation bound

**Algorithm STAR-SWEEP.**

1. Compute `I0` from the center bounds and center-only rows: `O(r0 + 1)` operations.
2. For each leaf, compute `L_i` and `U_i` on `I0` as sorted piece lists. Use the standard upper-envelope (convex-hull-trick) construction: sort the lines by slope, keep the largest intercept for each slope, and scan with a stack. A line `h` is popped when the intersection of its predecessor with the new line lies at or to the left of the intersection of its predecessor with `h`. Each line is pushed and popped at most once, so the cost is `O(s_i log s_i)`.
3. For each leaf, compute `J_i` (Lemma 2) by one merged scan of the two piece lists, solving one linear inequality per piece: `O(s_i)`. Set `I = I0 ∩ ⋂_i J_i`. If `I` is empty, stop with "empty". The two crossing endpoints give the witness: each is a vertex of some `P_j`, or an endpoint of `I0`.
4. If `lo = hi`, evaluate `L_i(lo)` and `U_i(lo)`, apply Lemma 4, and stop: `O(m + k)` operations.
5. For each leaf, clip its piece lists to `I`, compute `E_i ∪ R_i` and the rules (§3) in one scan: `O(s_i)`.
6. Form the events `(t, i, new rule)` for every rule change and sort them: `O(B log B)`, where `B <= 2m_L + 4k` (Theorem 3). Merging the `k` sorted lists with a heap costs `O(B log k)` instead.
7. Sweep from left to right. Maintain `(c0, c1, c2) = (a0, a1, a2) + sum_i contribution(rule_i)`; initializing costs `O(k)`. At each event, subtract the old contribution of the leaf and add the new one, `O(1)` per event. On each piece, evaluate the at most 3 candidates of Theorem 1. Keep the best candidate and the rules of its piece.

**Theorem 4 (operation bound).** Under (H1)–(H4), STAR-SWEEP decides emptiness, or returns the exact minimum, a rational minimizer, and the sorted partition with the rule changes at each breakpoint. It uses

```
O( sum_i s_i log s_i + B log B + r0 + k ) = O( (m + k) log(m + k) )
```

arithmetic operations and comparisons on rationals, with `O(m + k)` memory. The partition output with only the rule changes at each breakpoint (delta encoding) has size `O(m + k)`.

*Proof.*

- Correctness follows from Lemma 2 (steps 1–4) and Theorem 1 (steps 5–7).
- During the sweep, the running coefficients equal the coefficients of `Phi_j` on the current piece. This holds because every leaf whose rule changes at a point has an event there.
- Operation counts are given in the steps. Note that `sum_i s_i = m_L + 2k`. ∎

**Note on the inherited implementation.** `quadratic_star.py` intersects all pairs of lines, uses `O(s_i^2)` candidate breakpoints per leaf, and recomputes every leaf's rule on every piece.

- The audit's bound of `O((m + k + 1)^3)` operations is correct for it.
- Its certificate stores `k` rules per piece. A box star of `k` hinge leaves has `k + 1` pieces and `k(k + 1)` rule entries, verified for `k = 5, 10, 20`. So the certificate alone has size `Theta(k^2)`.
- The sharp bound needs the delta encoding.

## 6. Bit-size bounds

For a rational `r = p/q` in lowest terms, let `H(r) = max(|p|, q)` and `h(r) = log2 H(r)`. The encoding length satisfies `<r> <= 2h(r) + 3`. Elementary facts: `H(r*s), H(r/s) <= H(r)H(s)`, and `H(r_1 + ... + r_N) <= N * prod_j H(r_j)`. The last one holds because the numerator is `sum_j p_j prod_{l≠j} q_l`.

Let `sigma_i` be the maximum of `h` over the data of leaf `i` (`d_i`, `e_i`, `f_i`, `l_i`, `u_i`, and the row coefficients `p`, `b`, `c` of its rows). Let `sigma_0` be the same for the center data. Let `sigma = max_i sigma_i` and `Lambda = sum_{i=0..k} sigma_i <= L`, where `L` is the input length.

**Theorem 5 (sizes).**

1. Line coefficients satisfy `h <= 2sigma_i`. The free minimizer `v_i` has `h <= 2sigma_i + 1`.
2. Every point of `T` and every endpoint of `I` satisfies `h <= 12sigma + 4`. This bound is independent of `k`.
3. Every coefficient of every `Phi_j`, and every running sum in the sweep, satisfies `h <= C := log2(k+1) + sigma_0 + sum_i (11 sigma_i + 7)`, which is at most `11 Lambda + 7k + log2(k+1)` and hence `O(L)`.
4. The minimum value satisfies `h <= 4C + 36 sigma + 14`, which is `O(L)`. The minimizer satisfies `h(y*) <= max(12sigma + 4, 2C + 1)` and `h(x_i*) <= 4sigma_i + 3 + h(y*)`.

Hence STAR-SWEEP is strongly polynomial in the sense of [DK, p.3–4]. This uses exact rationals in lowest terms; gcd reduction has polynomial bit cost.

*Proof.*

Item 1: `c/b` and `-p/b` each have `H <= H(c)H(b)` or `H(p)H(b)`. For `v_i`, `-f/(2d)` has `H <= 2H(f)H(d)`.

Item 2:

- Intersecting two affine functions with coefficient heights at most `tau` gives `y = (alpha_2 - alpha_1)/(beta_1 - beta_2)`, with `h <= 2 + 4tau`. With `tau = 2sigma + 1` this is at most `8sigma + 6`.
- For the `g`-root: `g_0 = d(alpha_U + alpha_L) + f` has `h <= 1 + sigma + (1 + 4sigma) + sigma = 6sigma + 2`, and the same bound holds for `g_1`. So `-g_0/g_1` has `h <= 12sigma + 4`.
- Endpoints of `I` are `c/p` (`h <= 2sigma`) or intersections of two lines (`h <= 8sigma + 2`).

Item 3:

- For a rule `(alpha, beta)` with `h <= tau_i = 2sigma_i + 1`:
  - `d*alpha^2 + f*alpha` has `h <= 1 + 2sigma_i + 3tau_i = 8sigma_i + 4`.
  - `2d*alpha*beta + e*alpha + f*beta` has `h <= log2(3) + 1 + 3sigma_i + 4tau_i <= 11sigma_i + 7`.
  - `d*beta^2 + e*beta` has `h <= 8sigma_i + 4`.
- Each coefficient of `Phi_j` is the sum of `k + 1` such terms, which gives the bound `C`.
- By exactness, a running sum equals the coefficient of the current piece, whatever sequence of updates produced it.

Item 4:

- At a breakpoint `t`: the value is `c0 + c1*t + c2*t^2`, with `h <= log2(3) + 3C + 3h(t)`.
- At a stationary point: the value is `c0 - c1^2/(4c2)`, with `h <= 1 + C + (2C + 2 + C) = 4C + 3`.
- The bounds for `y*` follow in the same way, and `x_i* = alpha + beta*y*`. ∎

## 7. Lower bound: the operation bound is sharp

We use Ben-Or's theorem [M. Ben-Or, *Lower bounds for algebraic computation trees*, STOC 1983]. An algebraic computation tree may use `+ - * /` and square roots, and branch on signs. If it decides membership in a set `W ⊆ R^n` with `N` connected components, its depth is at least `c1 log N - c2 n`. STAR-SWEEP is such a tree for each fixed input format.

**Theorem 6 (lower bound).** For every `r >= 1`, consider star instances with `3r` leaves and `r` leaf rows. Any algebraic computation tree that decides "`min_D q >= -1`" for all such instances, with the data given as real inputs in a fixed format, has depth `Omega(r log r)`. Consequently, on instance classes with `m = Theta(k)`, the bound `O((m + k) log(m + k))` of Theorem 4 is optimal in this model, up to a constant factor. This holds even when only the value is required.

*Proof.* Fix `w = 1` and `R = 2r`. Let `W = {z in (0, R)^r : |z_i - z_j| >= w for all i ≠ j}`.

Step 1: `W` has `r!` components.

- `W` avoids every hyperplane `z_i = z_j`. So each component of `W` lies in one ordering cell `{z_{s(1)} < ... < z_{s(r)}}`.
- Within a cell, `W` becomes `{z in (0,R)^r : z_{s(j+1)} - z_{s(j)} >= w for all j}`. This set is convex and nonempty; for example, take `z_{s(j)} = j`.
- So `W` has exactly one component per ordering. By Ben-Or's theorem, deciding `W` requires depth `Omega(log r! - r) = Omega(r log r)`.

Step 2: the reduction. For `z in (0, R)^r`, build the following instance. The center satisfies `y in [0, R]`. For each `j` there are three leaves.

- `A_j`: `x in [0, 1]` and `q = ((y - z_j + w)/w) * x`. Its conditional value is `m_A = min{0, (y - z_j + w)/w}`.
- `B_j`: `x in [0, 1]` and `q = ((z_j + w - y)/w) * x`. Its conditional value is `m_B = min{0, (z_j + w - y)/w}`.
- `C_j`: `x in [0, R/w + 1]`, one row `y/w - x <= z_j/w` (that is, `x >= (y - z_j)/w`), and `q = 2x`. Its conditional value is `m_C = 2 max{0, (y - z_j)/w}`. The fiber is nonempty because `(y - z_j)/w < R/w + 1`.
- Center coefficients: `a2 = 0`, `a1 = -r/w`, `a0 = -r + sum_j z_j / w`.

With `t = (y - z_j)/w` and `T(t) = max{0, 1 - |t|}`, the identity

```
min{0, t + 1} + min{0, 1 - t} + 2 max{0, t} - t - 1 = -T(t)
```

holds. To check it, look at the cases `t <= -1`, `-1 <= t <= 0`, `0 <= t <= 1` and `t >= 1`. Hence

```
Phi_z(y) = -sum_j T((y - z_j)/w).
```

All data are affine in `z`, so they can be computed with `O(r)` operations. Inputs `z` outside `(0, R)^r` are rejected first, with `O(r)` comparisons.

Step 3: `min Phi_z >= -1` if and only if `z` is in `W`.

- Suppose `z` is `w`-separated. Three tents cannot be positive at the same `y`: their centers would lie within an open interval of length `2w` while being pairwise at least `w` apart. If two tents `i` and `j` are positive at `y`, then `T_i + T_j = 2 - (|y - z_i| + |y - z_j|)/w <= 2 - |z_i - z_j|/w <= 1`.
- Conversely, suppose `|z_i - z_j| < w`. At `y = (z_i + z_j)/2`, which lies in `(0, R)`, we get `T_i + T_j = 2 - |z_i - z_j|/w > 1`.

So a tree of depth `h` for the star problem gives a tree of depth `h + O(r)` for `W`. ∎

`M3_bounds_and_examples.py` checks the family on 60 random `z` with `r <= 7`, 12 of which have a forced coincidence. In every case the minimum equals `-max_y sum_j T`, and `min >= -1` holds exactly for the 30 `w`-separated instances. The first 6 instances also agree with the inherited oracle.

**Remarks.**

1. *Box-only stars (`m = 0`).* STAR-SWEEP takes `O(k log k)` operations. Producing the sorted, delta-encoded certificate requires `Omega(k log k)`. Take leaves `q_j = (y - z_j) x_j` on `[0,1]` with `z_j` in `(0,1)`. The optimal `x_j` switches from 1 to 0 exactly at `z_j`, so every valid partition contains all `z_j`. Element distinctness then reduces to a linear scan of the certificate. Whether the *value* of a box star can be computed in `o(k log k)` operations is open. The tent reduction needs rows, and this is not an accident: for fixed curvatures and bounds, the minimum is concave in the linear data `(a0, a1, e, f)`. So every decision set `{min >= theta}` is convex in those parameters, and Ben-Or's bound gives nothing.
2. For `k = O(1)` and many rows (a single polygon), we prove no lower bound beyond `Omega(m)`.
3. The lower bound concerns the algebraic model. No bit-model lower bound is claimed.

## 8. The gain corollary

**Corollary 7 (`cor:gain`, precise form).** Let `P_1, ..., P_k` be compact rational center–leaf polygons with common center coordinate. Assume `S := {(y,x) : (y,x_i) in P_i for all i}` is nonempty. Any additional center restriction must be included in every `P_i`. Let `q_i(y, x_i)` be rational quadratics, and define

- `beta_i = min over P_i of q_i`,
- `beta_* = min over S of sum_i q_i`,
- `Delta = beta_* - sum_i beta_i`.

Let `M_i` be the set of minimizers of `q_i` over `P_i`, and `pi` the projection onto `y`. Then:

1. `Delta >= 0`.
2. `beta_*` is the largest constant `c` such that `sum_i q_i >= c` on `S`.
3. `Delta > 0` if and only if `⋂_i pi(M_i) = ∅`.
4. `beta_i` and `beta_*` are computable exactly: `beta_*` by Theorem 1 (`sum_i q_i` is a star objective and `S` is a star domain), and each `beta_i` by Theorem 1 with one leaf.

*Proof.*

- Each `q_i(y, x_i) >= beta_i` on `S`, because `(y, x_i)` is in `P_i`. Summing gives item 1, and item 2 holds because the minimum is attained.
- Suppose `y` is in `⋂_i pi(M_i)`. Pick `x_i` with `(y, x_i)` in `M_i`. The resulting point lies in `S` and attains `sum_i beta_i`, so `Delta = 0`.
- Conversely, suppose `Delta = 0` and `(y, x)` attains `beta_*`. Then each term equals its own minimum, so `(y, x_i)` is in `M_i` for every `i`, and `y` lies in the intersection. ∎

**Checks.**

1. *Pair-hull witness.* `D1 = (y - 1/4 - x/2)^2 + x(1 - x)` and `D2 = (y - 5z/8)^2 + z(1 - z)` on `[0,1]^3`. Then `beta_1 = beta_2 = 0` and `beta_* = Delta = 1/128`, all exact.
2. *Pairwise intersections are not enough.* Let `y` be in `[0, 1]`, and take `q_1 = (y - x_1)^2` with `x_1` in `[0, 1/2]`, `q_2 = (y - x_2)^2` with `x_2` in `[1/2, 1]`, and `q_3 = y - y^2`. Then `pi(M_1) = [0, 1/2]`, `pi(M_2) = [1/2, 1]` and `pi(M_3) = {0, 1}`. These intersect pairwise but have no common point. Each `beta_i = 0`. The sum equals `dist(y, [0,1/2])^2 + dist(y, [1/2,1])^2 + y - y^2 ≡ 1/4` on `[0, 1]`, so `Delta = 1/4`. This value was confirmed by the inherited oracle, the M3 sweep, and exact KKT enumeration.
3. The example also shows that `pi(M_i)` need not be an interval.

## 9. Relation to Del Pia–Khajavirad (task item (a))

**Their model.** [DK] solve `min x^T Q x + c^T x` over `[0,1]^n` when the interaction graph (edges where `q_ij ≠ 0`) is a forest, using `O(n^2)` operations (Theorem 1, p.4). Rooted at a vertex `r`, the dynamic program is (p.4–5, eqs. (1)–(3)):

```
phi_v(x) = q_vv x^2 + c_v x + sum_{j in ch(v)} mu_j(x),     mu_v(t) = min_{x in [0,1]} [phi_v(x) + s_v t x],     s_v = 2 q_{p(v)v}.
```

The value functions `mu_v` are concave as pointwise minima of affine functions of `t` over the fixed set `[0,1]` (Lemma 2, p.5). Every `phi_v` therefore lies in the class of piecewise quadratics whose kinks are all concave. Their convex-envelope sweep (Lemmas 17–18, p.12–14) and the linear arc count (Proposition 1, p.9) both rely on this.

**Why the box star is a special case.**

1. A fixed variable (`l = u`) is substituted. A fixed center splits the problem into `k` scalar problems, and a fixed leaf adds only center terms.
2. For `l < u`, set `x = l + (u - l)*xi` with `xi` in `[0, 1]`, for the center and for each leaf. The cross coefficient `e_i` becomes `e_i (u_y - l_y)(u_i - l_i)`, so the interaction graph is unchanged: a star, possibly with isolated vertices where `e_i = 0`. This is a forest, and the constant term is irrelevant.
3. Center-only and leaf-only rows only shrink single-variable intervals, so they are still boxes.
4. Rooted at the center, each leaf child has `phi_j(xi) = q_jj xi^2 + c_j xi`. Its value function `mu_j(t) = min_{xi in [0,1]} [phi_j(xi) + s_j t xi]` is exactly our conditional value `m_j` in scaled coordinates. [DK, Lemma 9] lists its arcs `phi(0)`, `phi(1) + s t` and `-(s t + b)^2/(4a) + d`, which are our endpoint and clipping rules. The root problem `min_{[0,1]} phi_r` is the final step of Theorem 1.
5. So Theorem 1 restricted to boxes is an attributed specialization of [DK].
6. Operation counts. The root merge in [DK] costs `O(d_v m_v) = O(k^2)` for a star (p.15). Theorem 4 replaces it with sorting and costs `O(k log k)`. This is a minor improvement for this special case only, not a claim about their forest theorem.
7. If the star is rooted at a leaf instead, the center becomes a depth-two node. Its message can then have irrational breakpoints (§10). The specialization should root at the center.

**What center–leaf rows break.** A leaf row `p*y + b*x_i <= c` with `p ≠ 0` and `b ≠ 0`:

1. *No reduction to a box in general.*
   - For `k >= 2` with nonzero cross terms, the affine changes of variables that preserve the star sparsity are the triangular maps `y -> alpha*y + beta`, `x_i -> gamma_i*x_i + delta_i*y + epsilon_i`. Mixing a leaf into the center or into another leaf creates leaf–leaf products.
   - Such a map sends `P_i` to a rectangle only if `P_i` is a parallelogram `{y in I, a + delta*y <= x_i <= a' + delta*y}`: two vertical sides and two parallel lines, each active on all of `I`.
   - In that case the shear `x_i = xi_i + delta*y` gives a box star again. The new objective has the same shape, with cross coefficient `2d*delta + e` and center terms `(d*delta^2 + e*delta) y^2 + f*delta*y`, so [DK] applies.
   - For `k >= 2`, any other leaf polygon is outside [DK]'s model as stated: a triangle, a pentagon, a trapezoid with non-parallel lower and upper lines, or a polygon with two active lines on one side.
   - For `k = 1`, every affine map of the plane preserves the forest structure. So every parallelogram `P_1` reduces to a box, but no triangle or polygon with five or more sides does, because affine maps send rectangles only to parallelograms.
2. *The structural lemma fails.* With a `y`-dependent fiber, `m_i(y)` is no longer a minimum of affine functions of `y` over a fixed set. Example: `x` in `[0, 1]` with rows `x >= y - 1/2` and `x >= 1/2 - y`, and objective `x`. Then `m(y) = |y - 1/2|`, which has a convex kink. It was checked at `y = 0, 1/4, 1/2, 3/4, 1`: the values are `1/2, 1/4, 0, 1/4, 1/2`. So [DK]'s class of functions with only concave kinks, their envelope lemmas, and their arc counts are not available.
   - For a star none of these is needed: Lemma 5 describes each message directly, with `O(s_i)` rational breakpoints, and the root is minimized piece by piece.
   - For trees of depth at least two with edge-local rows, an internal message would require minimizing a piecewise quadratic with kinks of both signs over a moving interval. No polynomial arc bound or exact algorithm is established here. This remains open.
3. Rows confined to star edges do not change the interaction graph, which still has treewidth 1. So the treewidth-two hardness of [DK, §3] does not apply. This is consistent with Theorem 4.

## 10. Depth two: irrational breakpoints (task item (b))

**Example (path `x1 - x2 - x3`, box `[0,1]^3`).**

```
f(x) = (x2 - 1/8) x1 + x2^2 - x2 + x2 x3 + x3^2 - x3.
```

Root the path at `x3`, so that `x2` is an internal node with child `x1`. The message of the subtree `{x1, x2}` is

```
mu(t) = min_{x1,x2 in [0,1]} (x2 - 1/8) x1 + x2^2 - x2 + t x2,    t = x3 in [0,1].
```

**Claim.** On `[0, 1]`,

```
mu(t) = -(1 - t)^2/4   for 0 <= t <= tau,
mu(t) = -1/8           for tau <= t <= 1,
```

where `tau = 1 - sqrt(2)/2`. This `tau` is irrational: its minimal polynomial is `2t^2 - 4t + 1`. Yet `min f = -3/8`, attained at `x = (1, 0, 1/2)`.

*Proof.*

The message:

- The objective is affine in `x1`, so minimizing over `x1` gives `psi_t(x2) = min{0, x2 - 1/8} + x2^2 + (t - 1) x2`.
- On `[0, 1/8]`: `psi_t = x2^2 + t*x2 - 1/8 >= -1/8` for `t >= 0`, with equality at `x2 = 0`.
- On `[1/8, 1]`: `psi_t >= -(1 - t)^2/4`, with equality at `x2 = (1 - t)/2`. This point lies in `[1/8, 1]` exactly when `t <= 3/4`.
- For `t >= 3/4`, the minimum over `[1/8, 1]` is `psi_t(1/8) = t/8 - 7/64 > -1/8`.
- So `mu(t) = min{-1/8, -(1 - t)^2/4}`. The two arcs are equal where `(1 - t)^2 = 1/2`, that is, at `t = tau`, which lies in `(0, 3/4)`.
- `tau` is a genuine kink: the slopes there are `(1 - tau)/2 = sqrt(2)/4` on the left and 0 on the right. The kink is concave, as [DK, Lemma 2] predicts.

The global minimum:

- `min f = min over t in [0, 1] of [t^2 - t + mu(t)]`.
- On `[tau, 1]`, this is `t^2 - t - 1/8`, minimized at `t = 1/2`. Since `1/2 > tau ≈ 0.293`, the minimum there is `-3/8`.
- On `[0, tau]`, it is `(3/4)t^2 - t/2 - 1/4`. This is decreasing on `[0, 1/3]`, which contains `[0, tau]`, so its minimum on that piece is at `tau`. By continuity that value is `tau^2 - tau - 1/8 > -3/8`.
- The minimizer is `x3 = 1/2`, `x2 = 0`, and `x1 = 1` (because `x2 - 1/8 < 0`). ∎

**Mechanism, in [DK]'s terms (Lemma 17, p.13).**

- `phi_{x2}(x) = x^2 - x + min{0, x - 1/8}` has a concave kink at `1/8`.
- Its convex envelope on `[0, 1]` is the segment from `(0, -1/8)` tangent to the arc `x^2 - x` at `u = sqrt(2)/4`, followed by that arc.
- The minimizer of `mu` jumps across this segment at `t = -sigma/s = 1 - sqrt(2)/2`, where `sigma = 2u - 1` is the slope of the segment and `s = 1`.
- The irrationality therefore comes from the tangent drawn from an endpoint to a parabola. Breakpoints of this kind are quadratic irrationals, consistent with [DK, Lemma 12, p.10]: the arcs have rational coefficients, but the breakpoints are roots of quadratics.

**Path of four (`x1 - x2 - x3 - x4`).** Let `f4 = f + (x3 - 1/8) x4`. This is symmetric under reversing the path.

- The message of `{x1, x2}` to `x3` is the `mu` above.
- The message of `{x3, x4}` to `x2` is the same function.
- So for every choice of root, some non-root internal node sends a message with the irrational breakpoint `tau`.
- Exact face enumeration gives `min f4 = -3/8` at `(1, 0, 1/2, 0)`.

Rooted at the middle vertex, the 3-path is a star. The inherited oracle (with `center=1`) returns `-3/8` with the rational partition `[0, 1/8], [1/8, 1]`. Box constraints are a special case of edge-local rows, so the same obstruction applies with rows.

**Consequence for the paper.** The rational-partition proof of Theorem 1 does not extend to depth two by nesting messages. Exact deeper elimination needs [DK]'s algebraic representation `tau_0 + tau_1 sqrt(D)`, or something equivalent, even with boxes only. With rows, no such algorithm is established. The global minimum is nevertheless rational for every rational QP over a polytope [Vavasis 1990; DK Lemma 13].

All statements in this section are verified exactly (sympy, rational KKT enumeration) by `M3_irrational_breakpoint.py`.
