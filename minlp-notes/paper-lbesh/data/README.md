# Compact paper data

These immutable JSON extracts retain all 1,464 audited benchmark records, original outcomes including failures, work telemetry, continuous-root comparisons, oracle experiments, scope memberships, and all 51 generated coefficient sets. `provenance.json` records SHA-256 hashes linking each compact file to the final repository evidence. The source records are unchanged. The full research bundle supplies raw witnesses, saved schedules, logs, reference assignments and executable sources; this compact extract is sufficient to regenerate all paper tables and figures without that bundle.

Run from any working directory, with Python and Matplotlib installed:

```bash
python /path/to/paper-lbesh/scripts/regenerate.py
python /path/to/paper-lbesh/scripts/check_evidence.py
```

Use `--no-figures` for table/CSV regeneration with the Python standard library alone. The writing environment used Python 3.13.11 and Matplotlib 3.11.2. Regeneration checks immutable input hashes and complete batch counts before writing 17 table fragments, two PDF figures, `records.csv` and `table_values.json`. PDF timestamps are omitted; two successive runs gave identical bytes for all 21 outputs. The source LaTeX can be built directly with the supplied generated files and requires no Python or solver.

`records.csv` has one row per run/method/instance. `solved` means the original-model witness and numerical global-gap gate passed, not exact certification. `category` distinguishes numerical solve, feasible open gap, invalid witness, error, missing witness, unsupported input and process timeout. Missing values remain missing. All repeated and follow-up batches have distinct `run` fields. Times are seconds; nodes, iterations and cuts are counts. The `lp_iters` field counts iterations of the initial LP separation phase, not internal simplex or barrier iterations or all node LP solves. A phase iteration may include a second solve with dual reductions disabled after an ambiguous or unbounded status. The `time_cuts` field is recorded row-separation time per run: cumulative elapsed time in completed `_esh_cuts` calls, including row checks, radial searches when used, and linearization and coefficient work. It excludes initial tangents, NLP-solution tangents, normalization and transformation outside the routine, and installation in the master or callbacks. The `cuts` count also includes initial and NLP-solution tangents; its scope differs from the timer, so the reported mean-time ratio is not a per-cut cost ratio. In single-tree mode `time_master` includes callback work and overlaps `time_nlp` and `time_cuts`; do not add them. Cohort definitions and formulas are in the manuscript and regeneration script. The unrounded input fields remain in `records.json`; `table_values.json` contains displayed rounded entries.

`check_evidence.py` independently reconstructs the 51 parameter streams from the written generation order and verifies stored parameter hashes. It also checks or records every secondary numerical narrative statistic, including outcome counts, repeated categories/ranges, pilot comparisons, paired work, LP exits, ablations, cone-reference scope and scalar oracle counts. It does not re-evaluate primal model expressions; the separate fresh 1,464-record audit and 174-reference-witness validation are recorded in `evidence/stage03-independent-audit.json`.
