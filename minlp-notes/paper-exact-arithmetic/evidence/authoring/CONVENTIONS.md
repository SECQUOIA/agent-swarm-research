# Author conventions

All main writing uses Opus. Write only assigned sections/appendices and an author report. Read evidence/BRIEF.md. Do not change shared macros, main.tex, references.bib, another writer's files, or historical notes. No external literature research: the Luna lead provides evidence/literature-review.md and evidence/literature.bib; request missing sources through root. Use existing report bibliography keys when a source is already identified, or list proposed keys/needed sources in your author report for Luna verification. No experiments or mathematical script reruns.

Main section order (provisional): 00 introduction; 01 models; 02 points; 03 upper comparisons; 04 lower reductions; 05 constraints/integer selection; 06 singleton algebraic degree; 07 expanded output/moment/Gram height; 08 SOS fields/descent; 09 rational-function and block certificates; 10 cubic recourse; 11 implications/open questions. Long supporting proofs belong in the associated appendices. Every main claim needs a full proof here or a precise established external theorem with verified contract. Repository notes are source material, never external references filling a proof gap. Do not say 'see companion proof', 'independently reviewed', or describe repository history in paper prose.

Use L for total binary input length, n for ambient dimension, k for structural parameter, q for precision. Define every different local usage explicitly. Real/ordinary rational/shared arithmetic circuit/algebraic output models must be separated. Main upper label thm:exact-upper; certified quartic completeness thm:quartic-complete; global point label thm:global-point; cubic polytope point thm:cubic-point; generic quartic realization lem:quartic-realization; quadratic graph lift thm:quadratic-graph; singleton field thm:singleton-field; minimal SOS length thm:sos-length; rational-height thm:rational-height; circuit Gram thm:circuit-gram. Coordinate writers reference these labels only when logically necessary; report other needed shared labels.

Use macros.tex for existing macros. If an extra macro is essential, list the definition in your author report rather than edit macros.tex; common LaTeX operator notation also works. Keep labels prefixed with your topic except the shared labels above. No local filesystem links in manuscript. Explain why each result matters, not just its construction. Develop proofs analytically and critically; do not merely convert notes. As files appear under evidence/reviews/prewrite-*.md, incorporate the relevant audit findings and record responses. Raise unresolved blockers to root promptly. Main theorem scope must not rely on pending or finite computation claims. Conservative novelty and accurate attribution will be settled in integration with Luna's report.
