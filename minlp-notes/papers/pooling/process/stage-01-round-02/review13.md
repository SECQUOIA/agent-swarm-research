## Finding

### R13-1 — State the nonempty-product condition for the destination-relaxation ratio

- **Severity:** Minor; a local domain qualification, not a defect in the substantive sign or approximation result.
- **Location:** `01-foundations.tex:281–293`, especially the display at line 289.
- **Issue:** The paragraph introducing the destination-flow relaxation displays `z_rel <= z* <= z_best <= z_rel/m <= 0` without stating that `m = |J| >= 1`. Empty product sets are expressly permitted and handled at line 278. For `J = empty`, the destination relaxation and the physical acyclic flow set both contain only zero, so `z_rel = z* = 0`; however, `z_best` is not defined by the stated minimum and `z_rel/m` is undefined. The preceding theorem explicitly conditions its corresponding ratio on `m >= 1`, but the new paragraph should make that condition explicit as well. The cyclic counterpart does so at line 487.
- **Concrete boundary case:** Take one input, one isolated pool, no arcs, and no products, with all lower bounds zero and finite upper bounds. Both feasible sets are the singleton zero flow, but the displayed ratio contains division by zero.
- **Proposed correction:** Introduce the paragraph with “For `m = |J| >= 1`, there is also …” or qualify the display with this assumption. Optionally add that with no products the relaxation and physical optimum are both zero.
