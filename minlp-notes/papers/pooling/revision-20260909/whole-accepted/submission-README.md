# The Complexity of Pooling: Algebraic Barriers and Structural Algorithms

Build the manuscript from this directory with a LaTeX installation that provides pdfLaTeX, BibTeX, latexmk, and the standard packages loaded in `main.tex`:

```sh
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

The output is `main.pdf`. The source consists of `main.tex`, `bibliography.bib`, and the `sections/`, `appendices/`, and `figures/` directories. No external literature PDFs or repository verification files are required.
