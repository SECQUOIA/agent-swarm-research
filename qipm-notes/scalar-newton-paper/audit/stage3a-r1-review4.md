## Findings

1. **Minor — domain of the projected perturbation inequality.** In `sections/07-scalar-realizations.tex:584–589`, state `0 <= epsilon_v < 1` before the inequality. Without this, an admissible approximation may be zero, making the sampling probability undefined; and the reverse-triangle lower bound used in the upper denominator does not justify squaring `1-epsilon_v` when it is negative. All subsequent applications choose a sufficiently small epsilon_v, so their conclusions are unaffected.

2. **Minor — reusable setup needs a fixed success margin for constant overhead.** In `sections/07-scalar-realizations.tex:609–617`, replace “setup success exceeds one half” with “setup success is at least 1/2+c_setup for an absolute constant c_setup>0,” or use the conventional 2/3 guarantee. The conditional source decision should then have error below a sufficiently small constant depending on c_setup. Merely exceeding one half by a parameter-dependent vanishing amount does not justify a constant number of setups or the displayed cost with absolute constants. With the intended fixed bounded-error setup contract, the argument is correct.

3. **Minor — connect circuit synthesis tolerance to the sampling contract.** In `sections/07-scalar-realizations.tex:659–663`, the exact normalized-history identity is followed by a finite-synthesis gate cost. State explicitly that the implementation prepares that history to any requested Euclidean state error eta, with public gate cost polynomial in n, T, and log(1/eta); for example, allocate O(eta/G_public) operator error to each of the G_public public gates. This separates the exact algebraic state from its finite-gate implementation and directly identifies eta with the relative-vector sampling tolerance. The O(k) hidden-query bound is unchanged.
