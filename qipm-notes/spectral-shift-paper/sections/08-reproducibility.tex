\section{Reproducibility}\label{app:reproduce}
The source archive contains the complete \LaTeX{} manuscript, the bibliography and generated bibliography file, the required PDF figure, build instructions, and Python scripts. Building the paper with \texttt{make} requires \texttt{pdflatex} and \texttt{bibtex}, but not Python. The target \texttt{make figures} regenerates Figure~\ref{fig:overview} and supplementary threshold and pinned-kernel diagnostics using NumPy, SciPy, and Matplotlib. The scripts use paths relative to their own locations and require no external data or network access.

The threshold computation finds the unique solution of the stationary equation in Proposition~\ref{prop:threshold-asymptotics}, written in the offset variable $s=2r(t-\log R_0)$, which avoids subtracting nearby roots. It writes the computed thresholds and their comparison with the leading asymptotic term to CSV files. The overview script checks the closed formula for $G_1$ and the inequalities needed for the parity range shown in the figure. The supplementary diagnostic evaluates the identity for the signed error of the pinned construction near its contact points, which avoids subtracting nearly equal quantities. These floating-point calculations illustrate the proved formulas; sampled errors do not prove global nonnegativity or contractivity. The archive's README states the software versions used for reproduction and the individual script commands.
