## Stronger candidate: all-objective norm-tree distance coefficient

Root has now derived a possible complete replacement for the nonzero-subtree candidate above. This is NEW development requiring author verification and five formal reviews; do not treat this preparation as an accepted theorem.

Fix one root-normalized norm tree with b internal nodes, a unit leaf objective c, and its restricted standard barrier. Let alpha_v be the norm of c on leaves below v. Call v active if alpha_v>0. Let A be the number of active internal nodes, Z=b-A. The proposed exact fixed-instance asymptotic distance from ANY fixed interior reference to the gap-at-most-epsilon target is

    d(epsilon) = sqrt(A+Z/2) log(1/epsilon) + o(log(1/epsilon)).

This includes the earlier sqrt(b) result when every subtree is active and explains the sqrt(3/2) two-node example with an unused child. It is a metric-distance result for the specified barrier and tree, not an intrinsic optimal-barrier result. Products with positive objective weights add A+Z/2 over the involved trees; an entirely zero-weight independent tree need not move and contributes zero.

LOWER BOUND. For each active v, the Euclidean Lorentz dual

    y_v = (alpha_v, -alpha_u for internal children u, -c_j for leaf children j)

is nonzero rank one. For inactive v use y_v=0. Put beta_v=<y_v,x_v>. The pairings telescope to the objective gap g=1-c^T w, so 0<beta_v<=g. All internal coordinates satisfy t_v<=1. If u is a maximal inactive child of active v, the u-coordinate is perpendicular to the unit child direction of y_v. Lorentz feasibility gives

    t_u^2 <= ||child_perp||^2 <= 2 t_v beta_v/alpha_v <= 2g/alpha_v.

Every inactive descendant t_z<=t_u, so q_z=t_z^2-||children_z||^2<=C_c g, with a fixed positive constant depending on the finitely many active parents. Let

    Psi = -sum_active log beta_v - (1/2) sum_inactive log q_v.

In the full product standard metric, each active rank-one logarithm has squared dual gradient norm 1, and each inactive half-barrier has squared norm 1/2. Blocks are disjoint, so Psi has squared norm A+Z/2; affine restriction can only reduce it. At every gap<=epsilon point, Psi increases from its fixed reference value by at least (A+Z/2)log(1/epsilon)-O(1). Integrating gives the sharp proposed lower coefficient.

UPPER BOUND. Parametrize lambda->infinity and h=exp(-lambda). Assign local determinants q_v=h at active nodes and q_v=h/lambda^2 at inactive nodes. Set

    r^2 = 1-A h-Z h/lambda^2,
